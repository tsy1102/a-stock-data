### 错误 3 · `get_sht_report.py`（002360）流通市值与流通股本×现价不自洽
- **证据**：
  - `002360_sht_20260918_1804.md:12-13` → `总股本: 4.02亿股 / 流通股本: 3.26亿股`
  - `:21` → `现价: 5.33 元`
  - `:28` → `总市值: 21.41亿元 / 流通市值: 16.44亿元`
- **分析**：
  - 总市值自洽：4.02 × 5.33 = 21.43 ≈ 21.41（✓）
  - 流通市值不自洽：3.26 × 5.33 = **17.38 亿**，但报告写 **16.44 亿**（偏差 5.4%）；用昨收 5.83 算得 19.01 亦不符。
  - 即「流通股本 / 现价 / 流通市值」三者互斥，至少其一源数据或口径错误。
- **影响**：单股个例，但属字段级不一致，需在源侧复核（流通市值与流通股本是否取自同一快照）。
- **状态**：建议人工复核 002360 源数据；若为脚本层问题，需排查流通市值计算链路是否混用了不同价格基准。
