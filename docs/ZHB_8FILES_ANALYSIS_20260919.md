## 二、关键修正与发现（重要）

1. **tdxstat.cfg 第一列是市场标记位（`'0'`=深圳），真实股票代码在第二列。**
   项目解析器 `code = parts[1].strip()`（zhb_client.py:831）已正确跳过该列；docstring 的 `Col[N]` 为**含 market-flag 的 0-based 编号**，内部自洽。
   此前一次核查脚本误取 `split('|')[0]` 拿到 market-flag，导致"北交所覆盖=0"为**误判**，项目代码无误。

2. **北交所代码已全覆盖于 tdxstat 全市场快照。**
   真实代码（parts[1]）8055 只中，`92` 前缀北交所 **349 只已在列**（prefix2 分布含 `'92': 349`）。
   故 `addedcode_bj`（346 只新代码）/ `tdxbjmore`（349 只）是**元数据补充**（上市日、是否已切换/转板、老三板代码映射），而非代码缺失补全——这与 7 月"ZHB 补全北交所"的旧认知不同，需订正。

3. **`hqrule.dat` 已在上一轮落实**，返回 `CYBZDRatio=0.20`（创业板±20%）、`SH/SZGTDayMax=520`、`KCBOpenDate=20250922` 等 11 条规则，可替代硬编码涨跌停阈值。

## 三、8 文件逐一解析

### 1. hqrule.dat（已落实，复核）
- 编码 UTF-8，18 行，INI 风格 `[RULE]` + `KEY=VALUE`。
- 实测：`SHGTDayMax=520` `SZGTDayMax=520` `CYBZDRatio=0.20` `CYBZCDate=20200822` `MainAG_Cage=1` `KCBOpenDate=20250922` 等。
- 判定：**补充/替代**——使涨跌停阈值从硬编码改为动态读取。

### 2. tdxbk.cfg（58 行）
- 编码 GBK，`|` 分隔，`字段：[板块类]|[简称]|[全称]|[标志]`。
- 样本：`1|锂电池|锂电池概念|0`、`1|碳纤维|碳纤维概念|`、`3|北证专精|北证专精特新|0`。
- 承载：板块代码→简称/全称映射（如"锂电池"→"锂电池概念"）。
- 现有：项目已有 `spblock.dat`（大板块成分股，35208 行，段头如 `#融资融券`），但**无独立的板块显示名映射**。
- 判定：**展示层补充**（富化板块标签），零风险。

### 3. addedcode_bj.cfg（347 行，346 只）
- 编码 GBK，`|` 分隔。首行汇总 `000000,0,346,20260916,`；数据行 `44|832000|920000|安徽凤凰(已切换)|20251009`。
- 字段：`[市场]|[老代码/三板]|[新北交所代码920xxx]|[名称(状态)]|[上市日]`。
- 承载：北交所老↔新代码映射 + 名称 + 上市日 + 是否已切换/转板状态。
- 判定：**元数据补充**（tdxstat 已有 920xxx 代码，本文件补充上市日/切换状态）。

### 4. tdxbjmore.cfg（349 行）
- 编码 GBK，`|` 分隔 6 字段：`44|920000|2|安徽凤凰|1|`。
- 字段：`[市场]|[新代码]|[类型]|[名称]|[标志]`。
- 判定：**与 addedcode_bj 互补**，补充北交所类型/标志。

### 5. ilong.dat（907 行）
- 编码 GBK，`|` 分隔 `[前缀]|[指数代码]|[?]|[指数名称]`，含跨市场：`HZ` 前缀 309（港股/港股通指数）、`A1/A_`（美股 ADR）、`B1/B_`、`CE/CES`（中概）、`93/95`（债券）等。
- 样本：`62|CES100||中华港股通精选100`、`62|000985|||所有A股股票的综合指数`、`78|HST||Lion-OCBC Sec HSTECH`。
- 现有：项目 Grep 未见独立指数名称字典（指数名多经 TDX 行情实时解析）。
- 判定：**离线指数名称字典补充**，覆盖 A股/港股/美股/债券指数，可用于指数代码→名称解析与跨市场覆盖。

### 6. hspy.dat（22 行）
- 编码 UTF-8，`|` 分隔 `[市场]|[代码]|[缩写]`：`0|002839|ZJGH`、`1|603233|DSL`。
- 承载：沪深港通标的清单（22 只）。
- 现有：项目已有 `northbound`/`hsgt_flow` 沪深港通**资金流**缓存（stock_cache），但**未独立存储标的清单**。
- 判定：**低价值补充 / 疑似冗余待查**（22 只样本偏少，且资金流侧可能已隐含标的，需确认是否缺独立清单）。

### 7. tend_std.cfg（1013 行，100 个 [GROUP] 段）
- 编码 GBK，每段含 `BENCRYPTED=1` `GroupAttribute` `ParentName=主题投资` `Type` `Name01=概念名` `Title01` `ItemAttribute01` `Num`。
- 概念名样本：`NPO概念`/`PTFE概念`/`mRNA概念`/`SpaceX概念`/`摩尔线程概念`/`雅江水电概念`…（100 组热点/题材）。
- 承载：通达信"题材概念名称树"（含父分类层级）。
- 现有：项目 `get_concept_from_zhb` 是"个股→概念"映射，缺"概念名→分类层级"字典。
- 判定：**展示层补充**（富化概念标签层级，如"主题投资/人工智能"），低-中价值。

### 8. ihelp.dat（118766 字节，2463 行）— 黄金锚
- 编码 GBK，通达信客户端**栏目字典**，含全部指标权威定义。
- 关键印证（强力背书 tdxstat/tdxstat2 列语义）：
  - `涨幅：(现价-昨收)/昨收*100` → 印证 **tdxstat 涨幅列**
  - `市盈(动)：现价/折算成全年的每股收益` → 印证 **pe_dynamic**
  - `市盈(TTM)：最近12个月的每股收益` → 印证 **pe_ttm**
  - `封单额：涨停或跌停时买一/卖一的金额` + `昨封单额`/`前封单额` → 印证 **tdxstat2 三日滚动封单额**
  - `连板天：连续涨停板的天数` → 印证 **zt_lianban**
  - `股息率(TTM)...`/`换手`/`量比`/`委比`/`内外盘`/`总股本/流通股` 等均有定义
- 判定：**黄金锚（验证用）**，不接入运行；建议沉淀为 `docs/field_verification/` 列语义基准，供后续字段破解引用。

## 六、风险提示

1. `addedcode_bj`/`tdxbjmore` 的"切换/转板状态"字段语义（如 `(已切换)`/`(已转板)`）需一次抽样核验后再接入，避免状态误判。
2. `tend_std.cfg` 标 `BENCRYPTED=1`，其成分股指向可能加密；本分析仅用其**明文名称树**，不含成分股，接入安全。
3. `ilong.dat` 含港股/美股/债券指数代码（非 A股），接入时需按前缀过滤，避免污染 A股指数参照系。
4. tdxstat 列映射整体经多轮联网核实且数值区间合理，但"Col[N] 含 market-flag 偏移"此前未显式记录，建议对关键列（涨幅/PE/封单）做一次 cross-source 语义复核作为收尾。
