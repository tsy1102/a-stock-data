## 三、综合分析

### 3.1 关键发现

#### 发现 1：大多数策略在 top_n=100 就饱和

**02/04/06/13/22** 这 5 个策略在 100-1000 范围内都选满 10 个，说明它们的选股条件宽松，**top_n 进一步扩大无意义**。

**推荐 top_n：100**（节省网络/计算资源）

#### 发现 2：11/12/17 在 200 时稳定性提升最大

这三个策略的 Jaccard 稳定性：
- top_n=100：0.63
- top_n=200：**0.79**（+26%）
- top_n=300：0.80（+27%）

**推荐 top_n：200**（稳定性 0.79 已足够，再大无明显提升）

#### 发现 3：05 W底形态是真正"需要 300"的策略

05 的选中数曲线：
- top_n=100：0.8（< 1，几乎选不到）
- top_n=200：7.5
- top_n=300：10.0（饱和）

**推荐 top_n：300**（条件严苛：60日跌 + 20日反弹，需要大池子）

#### 发现 4：19 52周低位在 200 时稳定性最佳

19 的 Jaccard 稳定性：
- top_n=100：0.37（很差）
- top_n=200：**0.77**（峰值）
- top_n=500：0.67（反而下降）
- top_n=1000：0.46（大池子引入噪声）

**推荐 top_n：200**（刚好"够用"的最大值）

#### 发现 5：20 主力资金是"条件最严苛"的策略

20 的选中数随 top_n 线性增长：100→0.5, 200→2.5, 1000→9.5，始终选不满 10 个。

**结论**：策略条件（main_net_buy_amount / amount ≥ 3%）本身就严苛，需要扩大池子。

**推荐 top_n：1000**（但即便 1000 也只能选 9.5 个，建议**降低阈值**而非继续扩大 top_n）
