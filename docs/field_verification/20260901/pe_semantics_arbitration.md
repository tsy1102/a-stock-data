# PE 语义仲裁：f162 / f163 / f164 究竟谁是静态·动态·TTM

## 一、方法

**不采信任何来源的中文标签**（同花顺 pe_mrq / 东财『市盈率(动态)』/ TDX『静态』互不一致），改用**闭式数值反推**——由 EPS 基数反算三种 PE 定义，看谁精确命中。

| PE 口径 | 定义 | 本项目可用 EPS 基数 |
|---|---|---|
| 静态 PE(LYR) | 现价 ÷ **上年度年报** EPS | `f160`（字典已定案=年报EPS）|
| 动态 PE(年化) | 现价 ÷ (**最新报告期** EPS × 年化系数) | `f55`（EPS基本）|
| TTM PE | 现价 ÷ **最近12个月** EPS | `f108` |

> 采集窗口 2026-08-24~08-31，A 股最新报告期为 **2026 中报** → 年化系数 **×2**。

## 四、交叉验证：f108 究竟是不是 TTM EPS

用净利同比 `f185` 反推 2025H1 EPS，检验 f108(TTM) 是否自洽：

    TTM_EPS = 2025年报EPS − 2025H1_EPS + 2026H1_EPS
    而 2026H1/2025H1 − 1 = f185(净利同比)

- f185 净利同比 = -1.951594855028%
- 反推 2025H1 EPS = f55 ÷ (1+f185/100) = 35.611179611 ÷ 0.980484 = **36.3200**
- 反推 TTM EPS = 65.851754826 − 36.3200 + 35.611179611 = **65.1429**
- 实测 f108 = **65.142935597**
- 差 = 0.0000 → ✅ 自洽，f108 确为 TTM EPS
- 由 f108 反算 TTM PE = 1299.52 ÷ 65.142935597 = **19.9487**，实测 f164 = **19.95** → ✅ 完全吻合

## 五、结论

1. **f164 = TTM PE**（现价 ÷ f108，f108=TTM EPS，经 fuyao `pe_ttm` 120/120 与净利同比闭式双重验证）—— 三方一致，**字典正确**。
2. **f163 = 静态 PE(LYR)**（现价 ÷ f160 年报 EPS）—— 字典 2026-08-31 改写为『动态』**错误**。
3. **f162 = 动态 PE（最新报告期年化）**（现价 ÷ f55×2）—— 字典 2026-08-31 改写为『静态/MRQ』**错误**。
   - 根因：把同花顺官方名 `pe_mrq` 的 **MRQ=Most Recent Quarter（最新报告期）** 望文生义译成『静态』；
     而 MRQ 口径在计算上正是『最新报告期年化』= 中文语境的**动态市盈率**，与东财客户端显示『市盈率(动态)』一致。
4. **这正是用户所指『不同源标注语言差异导致误解』的又一实例**：同花顺 `pe_mrq` = 东财『动态』= TDX『静态』，**三个名字一个值**。
