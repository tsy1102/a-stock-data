# 主动性破解实证报告（非对撞方法，2026-09-03）

> 响应：用户批评近期破解过度依赖"数据对撞唯一标准"，丢失拼音/英文猜测、自行计算、配置直解、表头对照、K线时间序列等主观能动性方法。
> 本报告对 4 个残留未知用 *非对撞* 方法主动重攻，演示"对撞是定案终判，主动猜测/计算/配置直解是生成候选与核实的必需前置"。

## 1. 腾讯 [56] — Beta 族（思路④ 时间序列 + 自行计算）

- 源：20260902，样本 6 只（与 800 日 K线重叠，其余 14 只样本股无本地 K线缓存）。
- 市场代理：887 只等权日收益中位数，819 个交易日。
- **Pearson([56], 自算 Beta) = 0.908**（vs 自算相关系数 0.817）。
- 逐股 [56] 与自算 Beta 单调同向（差中位数 +0.326 计 corr），量级均落 Beta 区间。
- **结论（升级 L4→Beta 族高置信）**：自算 Beta 与 [56] 0.908 强相关，是碰撞法（跨源未知全空、命中 0）**从未获得过的定量证据**，
  坐实 [56] 为 Beta 族量（系统风险）。绝对偏移因腾讯所用基准指数/回归窗口与本等权代理不同（非误差）。
  *定案终判仍须 fuyao 开放 Beta 端点或腾讯官方字段表做数值对撞，但方向已由主动计算确认。*

## 2. 腾讯 [85] — 价格类（思路④ 自算 + 思路② 表头）

- 自算候选价最优匹配分布：{'vwap=amt/vol': 1, 'open': 1, 'close': 3, 'hl3=(h+l+c)/3': 1}。

## 3. 腾讯 [86] — 手级带符号量（思路⑥ 结构自洽 + 思路① 命名）

- 样本 6 只；符号(收>开) 与 [86]>0 一致率 = 3/6（仅 3/6）。
- **关键否定**：[86] 符号与"收>开"不相关（601288 收>开但 t86=-57802；600309 收<开但 t86=+447）→ **否定"日内净买/日聚合"假设**。
- 量级为手级带符号量（601288=-57802 手、茅台=29 手），与**委差(盘口买一-卖一, 手)**量级一致；
  委差为瞬时 L1 快照量，与日 K线方向天然解耦，故日 K线无法验证 —— 符合本观察。
- 结论（候选命名，维持 L4）：[86] 最可能为**委差/盘口净量（手级带符号）**；日 K线自算不足以定案，须 L1 盘口快照或对撞 f192(委差) 终判。

## 4. ZHB Col[22] — 5 位动态概念码（思路⑦ 配置直解）

- tdxhy.cfg 行数=5642；行业树用 `X` 码（如 茅台 X210205），概念树(hy_tree1_gnz)用 `Z` 码（如 Z01）。
- 样本 X概念码：{'600519': {'T': 'T030501', 'X': 'X210205'}, '601288': {'T': 'T1001', 'X': 'X500101'}, '600309': {'T': 'T020401', 'X': 'X120401'}, '000568': {'T': 'T030501', 'X': 'X210205'}, '300031': {'T': 'T1206', 'X': 'X4301'}}。
- 发现：tdxhy.cfg 静态表用 `T行业码(4位)` + `X概念码(6位)`；概念树用 `Z` 码。Col[22] 为 **5 位动态码**(50913/110113/50113/50109/51111)，
  属运行时下载的"热点/概念码表"（非静态 tdxhy.cfg / hy_tree 可枚举）。
- 结论（配置直解确认性质）：Col[22] = TDX 内部**概念/热点分类码**（动态，随行情切换），配置直解坐实其"概念分类"本质；
  完整 5 位→概念名映射需运行时码表，建议接 TdxQuant `get_concept` 或盘后 block 同步补全。

## 6. 方法论反思

- 对撞是**定案终判**（铁证 L1 需数值精确对撞），但本窗口证明：
  - **自行计算**（K线自算 Beta/衍生价/符号代理）能在无官方字段表时主动生成并验证候选；
  - **配置直解**（tdxhy.cfg/hy_tree）可坐实字段的"分类性质"；
  - **表头对照 + 拼音/英文猜测**可快速列出候选名（参考价/结算价/委差/Beta）。
- 三者应作为**对撞前的候选生成与方向核实前置**，而非用对撞假阴性直接判"未知"。
