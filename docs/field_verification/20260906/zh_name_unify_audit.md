# 主字典跨源同义字段·中文名统一审查（2026-09-06）

## 一、目的

主字典是采集脚本的**字段依据**：脚本按「中文名」取数 → 经字典映射到「源字段编号」→ 取各源数据 → **对撞**（跨源比较）以判定真实语义。

因此只要存在「同一含义、不同中文名」，对撞就会错位甚至全错。本轮目标：**每个语义只保留一个中文规范名**，消除跨源异名。

## 二、源边界界定（按源审查，不合并）

| 源 | 说明 |
|---|---|
| 东财 push2 | **一个源**，含 `stock/get`、`ulist.np/get`、`kline/get`、`push2ex` 等端点。f43 与 f2 只是**端点不同编号**，同属「现价」，**不得当两个源** |
| 腾讯 qt.gtimg.cn | 独立源（`[idx]`） |
| 新浪 hq.sinajs.cn | 独立源（`[idx]`） |
| THS SDK（TCP） | 独立源（数字 ID），**不与 fuyao 合并** |
| fuyao REST | 独立源（THS 官方，英文 snake_case） |
| TDX | **多个源**：GetFinanceInfo 0x0010、实时快照、短线指标、func 配置字段 |
| ZHB | **一个源**（`tdxstat.cfg`/`tdxstat2.cfg`/`tipinfo.dat` 同属 ZHB，不拆分） |
| 开盘啦 / KPL | 独立源 |

## 三、中文名基准（优先级递减）

1. **通达信官方 1,924 字段表**（`docs/verify/tdx_func_fields.md`）
2. **同花顺 tableheader 中文列名**（§零·C、`docs/verify/ths_tableheader_ids.md`）
3. **东财客户端表头 A–G 系**（`docs/verify/em_tableheader_ids.md`）
4. 英文键（fuyao snake_case / push2 `fN` / 腾讯 `[idx]` / TDX code）**一律降为别名**

> 已弃用 fuyao 的中文释义作规范名：其官方契约只提供"英文字段名 + 中文释义"，
> 且释义本身不统一（`open_price` 在快照端点写"当日开盘价"、K线端点写"开盘价"），不适合当规范术语。

**通达信覆盖度实测**（`scratch/check_tdx_coverage.py`）：核心语义 **32/43**；
缺失 11 项（涨跌额、涨跌幅、振幅、量比、涨停价、跌停价、委比、委差、内盘、外盘、52周）由同花顺/东财补齐。

**保留不动**：铁律中列举旧称的映射说明、新浪接口返回格式原文（接口契约原文，改写会破坏可追溯性）。

## 七、已知风险

1. **通达信 `pe_ttm` 官方中文为「市盈率(动)」**，与本项目已定案口径（动=f162 报告期年化、TTM=f164）**相反**。总表按项目口径命名，通达信命名仅备查，勿据此改写语义。
2. **单位陷阱**：规范名统一 ≠ 数值可直接对撞。成交量（手/股，腾讯 688 段为股）、成交额（元/万元）、市值（元/亿元）仍须先归一。
3. 同花顺 tableheader 原始 682 列仅沉淀 89 行摘录，本机已无 `tableheader\*.ini`，中文基准存在覆盖上限。
