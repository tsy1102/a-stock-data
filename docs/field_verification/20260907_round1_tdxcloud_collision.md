## 四、本轮核心结论

1. **tdxstat 财务列破译获双源/三源锁定**：Col[14]=扣非净利、Col[24]=货币资金，经「东财F10(原) + 本地easy_tdx F10(本轮) + 云CwInfo净利润旁证(600519)」三方一致，证据强度由「单源推断」升为「多源确认」。
2. **云 CwInfo 发现可补源字段**：`YSZK`应收账款/`CH`存货/`LDFZ`流动负债/`GDRS`股东人数 等命名值，项目 canonical 当前**未从 TDX 取**（仅经东财 F10）。这些是用户「倒推未破解字段」思路的正面产物——云连接器让这些**已命名、可直取**的 TDX 财务字段浮出水面，未来可作为 TDX 源补入 canonical（独立于东财）。
3. **云连接器可用性边界（重要）**：
   - F10 **原始三表（资产负债表/利润表/现金流量表）在云端点未注册**（`功能未注册` / `-1005 数据库执行失败`）→ 不能依赖云拉原始财报。
   - 云 `tdx_quotes` 实时可用但**偶发 503**（本轮 4 只仅 600519 成功）。
   - 故云连接器适合做**命名值 oracle / 字段目录发现**，不适合做**批量/稳定取数源**——与「AI 碰撞工具」定位一致。
