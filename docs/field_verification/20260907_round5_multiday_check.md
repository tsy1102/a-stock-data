# 第五轮碰撞实测：多日聚合资金流字段破译验证

> 目的：用户猜测 push2delay 采集数据中「未破解字段」可能是 **5日 / 20日 / 60日** 主力净流入的区分；并强调**按交易日而非自然日**滑动。
> 方法：用项目既有连续采集（`docs/field_verification/20260812~20260906`，共 18 份 `raw_ulist239.json`，覆盖约 17 个真实交易日）做内部计算验证，不引入任何新源。
> 靶子：`ulist239` 的 600519（茅台，每期均在）全部 f-字段。日基准 = `f62`（日主力净流入，已证 = `em_fund_flow.f137`）。

## 一、数据家底
- `raw_ulist239.json`：18 份（0812/0813/0814/0815/0819/0820/0822/0824/0825/0826/0827/0828/0831/0901/0902/0903/0904/0906）。0906 为周日快照，f62 复用 0904 值。
- 交易日序列（按日期名即交易序，非自然日）：0812→0904 共 17 个有效日；0906 为周末重复点。
- `raw_em_fund_flow.json`（仅 5 份，0901-0906）：f135-f149 当日级，已证 `f135-f136=f137`=当日毛额差，无多日聚合。

## 二、f164 = 5日主力净流入 —— ✅ 假设成立（强证据）
逐日期用「最近 5 个有效交易日的 f62 之和」比对 f164：

| 日期 | f164(实际) | 5日f62和(计算) | 判定 |
|---|---|---|---|
| 0819/0820/0822/0824 | -553M / -1237M / -2048M / -1177M | 746M / 374M / -578M / -811M | ✗（窗口缺 0810/0811 历史） |
| 0825 | -1,228,555,968 | -1,228,555,968 | ✓ |
| 0826 | -1,064,716,624 | -1,064,716,624 | ✓ |
| 0827 | -1,101,498,512 | -1,101,498,512 | ✓ |
| 0828 | -579,902,208 | -579,902,208 | ✓ |
| 0831 | -599,754,272 | -599,754,272 | ✓ |
| 0901 | -179,742,160 | -179,742,160 | ✓ |
| 0902 | -284,248,672 | -284,248,672 | ✓ |
| 0903 | 167,373,280 | 167,373,280 | ✓ |
| 0904 | 607,453,040 | 607,453,040 | ✓ |

**0825→0904 连续 10 个日期零误差吻合**（含跨周末 0828→0831、0831→0901 的交易日跳跃）。前 4 个 ✗ 完全可解释：真实 5 日窗口对 0819/0820/0822/0824 需回溯到 0810/0811（采集前），我们缺这段历史故窗口错位。**这反而证明 f164 严格按「交易日」滑动** —— 若按自然日，跨周末的 0825 之后不可能精确吻合。
→ **结论：f164 = 最近 5 个交易日 f62 之和（5日主力净流入）。用户「交易日非机械自然日」直觉成立。**

## 三、f165 = 5日主力净流入占比(%) —— 结构配对确认
`f165 / f164` 的符号与量级逐日一致（f164 正→f165 正，f164 负→f165 负，比值同量级）。精确分母待定（疑似流通市值或成交额，非简单 f51；0904: f164=607M, f165=3.34, f164/f51×100=0.23 → 非 f51 直接除，需另查分母）。**结构层面 f165 是 f164 的 % 形式伴侣，结论稳健。**

## 四、f168(10日) / f174(20日) —— ⚠️ 不等于 f62 简单滚动和
| 日期 | f168(实际) | 10日f62和 | f174(实际) | 20日f62和 |
|---|---|---|---|---|
| 0904 | 214,083,680 | 27,550,832 | 27,550,832 | 27,550,832 |
| 0903 | 16,346,688 | -934,125,232 | -934,125,232 | -934,125,232 |
| 0902 | -42,666,656 | -1,348,965,296 | -1,348,965,296 | -1,348,965,296 |
| 0901 | 159,765,904 | -1,408,298,128 | -1,408,298,128 | -1,408,298,128 |

**f168/f174 与 f62 的 10/20 日滚动和均不匹配**，且 0904 的 10 日窗口（0824-0904）完全在采集范围内仍不符 → **排除「仅缺历史」解释**，指向：东财对 10/20 日长周期使用**独立的「历史资金流」序列**（与实时 f62 口径/源不同），或日基准字段非 f62。
→ **结论：f168=10日、f174=20日 主力净流入的语义方向合理，但「= f62 滚动和」这一具体算法被证伪；需另查东财历史资金流 API 方能钉死。**

## 五、60日 —— 不可验
本数据仅 17 个交易日，远不足 60 日窗口。需补 0810 之前 ≥60 日历史方可验证（属下一步）。
