## 一、L1 定案明细（跨源三方一致，已 spot-check 复核）

### 1. `f142` = **买二价 (bid2)**
- **证据**: `tdx.quote_full.bid2` / `sina[14]` / `腾讯[12]` 三者均于 **16 个采集日 rate=1.0、Spearman=1.0** 精确等于 ulist f142。
- **spot-check（茅台 600519）**: `ulist f142 = 1297.40` = `tdx bid2 = 1297.40` ✅ 逐字等。
- **语义**: 五档盘口第二档买价。纠正了第七轮前「资金流」误判路径（f142 非资金流字段）。

### 2. `f143` = **卖二价 (ask2)**
- **证据**: `tdx.quote_full.ask2` / `sina[24]` / `腾讯[22]` 三者均于 **16 个采集日 rate=1.0、Spearman=1.0** 精确等于 ulist f143。
- **spot-check（茅台 600519）**: `ulist f143 = 1297.55` = `tdx ask2 = 1297.55` ✅ 逐字等。
- **语义**: 五档盘口第二档卖价。

### 3. `f160` = **20日涨跌幅% (腾讯[70] 口径)**
- **证据**: `腾讯[70]` 于 **16 个采集日 rate=1.0、Spearman=1.0** 精确等于 ulist f160。
- **spot-check（茅台 600519）**: `ulist f160 = -0.79` = `腾讯[70] = -0.79` ✅。
- **⚠️ 同名异义关键修正**: `ulist f160` **≠** `push2 f120` / `ulist f110`（后者才是 push2 口径的 20日涨跌幅%，茅台实测 `f110 = push2 f120 = -0.69`，而 `f160 = -0.79`）。
  - 全样本核验：`ulist f110 ↔ push2 f120` 命中 **361/378=95.5%**；`ulist f160 ↔ push2 f120` 命中 **7/378=1.9%**；`ulist f160 ↔ 腾讯[70]` 命中 **335/357=93.8%**。
  - 故 **腾讯[70] 与 push2 f120 是两类不同的 20日涨跌幅指标**，字典原 line 1363「`腾讯[70]=push2 f120×100`」为**错误断言**，已订正为「`腾讯[70]=ulist f160`（第九轮跨源定案）；与 push2 f120/ulist f110 非同一口径」。
  - 另注：`ulist f160`（腾讯口径）与 `push2 f160`（年报EPS，见 §五 对照表）是**不同字段**，勿混淆。

## 二、本轮关键纠错（铁律兜住的两个伪命中）

### ① `f190 = tdx hgu` 是「退化锚伪命中」——已剔除，f190 维持待核实
- 初版对撞（无锚退化护栏）曾将 `f190` 误判为 `tdx hgu`（H股股数，rate 0.95 / 18日）。
- **深度核验揭穿**：ulist239 语料 20 股**全为纯 A 股（无 H 股）**，`tdx hgu` 在样本中 **95% 为 0**；`ulist f190` 同样 **95% 为 0**（非0值恒为 `3.0`，疑似分类/标志位）。二者「都空=都空」撞出高命中率是**同号即同义铁律的镜像伪命中**（同 round-8 `f250` 空标记伪命中）。
- **补锚退化护栏**（`anchor_degenerate`：众数占比 >90% 或 不同值 ≤2 即跳过）后重跑，`f190` 正确降为 L4 弱候选（仅 `bid1_vol` 等 1 日 rate 0.85），**不得收口为 hgu**。
- `f190` 实测分布：380 对中仅 19 非0、且全为 `3.0` → 语义待定（疑似板块/标志类），**维持 `⚠️ 未实证·待核实`**。

### ② `f160 ≠ push2 f120` —— 纠正字典 line 1363 的「`腾讯[70]=push2 f120×100`」错误
- 见上一节 §一.3。该错误使「腾讯[70]」与「push2 f120/ulist f110」被误认为同一指标；实证二者为不同口径，已订正。
