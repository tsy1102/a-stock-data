## 1. 核心结论（先行）

**`tx[7]` = 外盘（主动买盘量）、`tx[8]` = 内盘（主动卖盘量）成立**，由三源交叉确认。Round12 的「矛盾/并非内/外盘」结论系误判，根因有二：

1. **跨源精确相等要求不当**：腾讯采集与 TDX 快照存在数分钟级时差，内/外盘为累计量，跨源天然有 ~1~3% 漂移；要求精确命中必然 0/20。
2. **科创板单位未归一**：Round12 脚本对所有股票统一 `×100`（手→股），但腾讯 `tx[7]/[8]` 仅**科创板(688)**按股计、其余板块按手计。对非科创板误乘 100 制造出伪"10×"量级差。

## 2. 三源证据

### 2.1 push2 `f49/f161` ≡ 腾讯 `tx[7]/tx[8]`
- `f49 == tx[7]` 精确命中 **13/20**；`f161 == tx[8]` 精确命中 **13/20**（全部非科创板逐股相等）。
- 科创板(688)呈 `tx[7]/100 == f49`（股 vs 手，整数取整）；北交所(920) ratio≈1.01（仅快照漂移）。
- 例：000007 `tx[7]=54100 / f49=54100`、`tx[8]=55415 / f161=55415`（精确相等）。
- 例：688327 `tx[7]=6734547(股) / f49=67345(手)`、`6734547/100=67345.47≈67345`。

### 2.2 逐板块 `sum(tx[7]+tx[8]) / TDX成交量` 单位锁定
| 板块 | `sum/(TDX_vol 手)` | `sum/(TDX_vol×100 股)` |
|---|---|---|
| 沪主/深主/创业板/北交所 | **1.000** | 0.010 |
| 科创板(688) | **100.000** | **1.000** |

→ 非科创板 `tx[7]+tx[8]` 即总成交量（手）；科创板为总成交量（股）。单位铁律：**腾讯/push2 内/外盘——科创板按股(×100)，其余按手；TDX `inside/outside` 全按手**。

### 2.3 TDX `Inside/Outside` 一致性
- TDX `Inside + Outside == Volume` **20/20** 自洽（单位=手）。
- 单位归一后（科创板 `tx[7]/100`），`tx[7]/TDX_Outside` 非科创板 ratio≈0.94~1.06、科创板 `tx[7]/100/TDX_Outside≈0.87~1.03`——均落在快照漂移区间，确认同一语义。

## 4. 方法学修正（写入 SOP）

对**量派生字段**（内/外盘、成交量族）做跨源对撞时：
1. **用比值≈1 判定，不用精确相等**——累计量受快照时差影响，~1~3% 漂移属正常。
2. **必须逐板块单位归一**——A 股存在板块单位陷阱（科创板内/外盘按股、其余按手；涨停/跌停价 10%/20% 板等），统一乘/除 100 会制造伪差。
3. **优先找第三源做配对验证**——push2 `f49/f161` 与腾讯 `tx[7]/tx[8]` 的精确配对，比单靠 TDX 快照比值更硬。
