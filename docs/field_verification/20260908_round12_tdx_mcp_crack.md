## 3. 焦点三：内/外盘 —— ❌ 原「矛盾」结论已推翻，✅ 三源确认 tx[7]=外盘/tx[8]=内盘

> 🔥 **ERRATA（2026-09-09 专项复核更正）**：本节初版（Round12）以「TDX 锚 0/20、×100 后仍差约 10×」判定 `tx[7]/[8]` 并非内/外盘，**系误判**。根因：① 要求跨源精确相等，但腾讯采集与 TDX 快照有数分钟时差、内/外盘为累计量，天然 ~1~3% 漂移；② 对非科创板股票误乘 ×100（如 000007 本应 `tx[7]=54100 vs TDX外盘 53347`，ratio 仅 1.4%，却被写成 `53347×100=5.3e6` 伪"10×"）。详见 `20260908_inner_outer_review.md`。

**正确结论（三源交叉确认）：**

1. **push2 第三源精确配对**：`f49 == tx[7]` 精确 **13/20**、`f161 == tx[8]` 精确 **13/20**（全部非科创板逐股相等）；科创板呈 `tx[7]/100 == f49`（股 vs 手，整数取整），北交所 ratio≈1.01（仅快照漂移）。
2. **逐板块单位锁定**：`sum(tx[7]+tx[8]) / TDX成交量` —— 非科创板 **=1.000**（手）、科创板 **=100.000**（股）。单位铁律：**腾讯/push2 内/外盘，科创板按股(×100)、其余按手；TDX `inside/outside` 全按手**。

→ **`tx[7]`=外盘（主动买量）、`tx[8]`=内盘（主动卖量）成立**，与既有字典标注一致；Round12 的⚠️矛盾标记撤销，升级 canonical（见 §7.5 与 `field_dict.md` 行 3089–3090）。
