## 一、tx[56]：第四源独立 Beta 锚建设

### 1.1 锚构造

- 用通达信 MCP `tdx_kline` 取 **19 只个股 + 沪深300(000300) + 中证全指(000985)** 前复权日线（period=4, wantNum=260，剔除 1 根盘前 Volume=0 空量根 → 259 有效根）。
- 取 20 个 `tdx_kline` 返回文件（超限自动落盘于 tool-results），经 `json.JSONDecoder.raw_decode` 解析 `Rows[]` 提 Close 序列，落盘 `raw_tdx_kline_beta.json`。
- 日收益率 `r_t = Close_t / Close_{t-1} − 1`，按公共交易日对齐。
- Beta 定义（OLS 斜率）：`β_i = Cov(r_i, r_mkt) / Var(r_mkt)`，市场代理取两种：
  - **窄基准**：沪深300（000300）
  - **宽基准**：中证全指（000985，全 A 宽基）
  - （对照）等权组合（18 只个股等权，复现第 09-03 主动法）

### 1.2 三基准对撞结果（n=18）

| 市场代理 | 拟合式 | R² | Pearson r | Spearman ρ |
|---|---|---|---|---|
| 沪深300（窄） | tx56 = 0.224 + 1.261·β | 0.9348 | **0.9669** | 0.9670 |
| **中证全指（宽）** | **tx56 = 0.271 + 1.066·β** | **0.9819** | **0.9909** | **0.9880** |

**关键判读**：
- 随基准由窄（沪深300）→ 宽（中证全指），拟合优度单调提升（R² 0.935→0.982，Pearson 0.967→0.991），斜率由 1.261 收敛至 **1.066≈1.0**。
- 这**唯一地定位 tx[56] 的真实基准类别为「宽基全市场指数」（类中证全指 / 国证A指）**，而非此前猜测的沪深300。与腾讯行情终端普遍以全 A 宽基作 Beta 基准的工业实践一致。

### 1.4 管道有效性自检（排除误算）

第 09-03 主动法曾出现农业银行 β 为负引疑虑。本轮用全窗口累计收益复核：

- 沪深300 +8.5%、中证全指 +8.9%、农业银行 +2.4%（显著跑输指数 → 负 Beta 真实）、贵州茅台 −4.4%（逆市下跌 → 低 Beta 真实）。
- 农业银行 vs 沪深300 日收益 Pearson = −0.229（弱负相关，与负 Beta 一致）。
- **结论：自算 Beta 管道正确，负/低 Beta 为样本窗口真实特征，非计算缺陷。**

## 二、tx[56] 终判定级

**结论：tx[56] = A股系统风险 Beta，基准为宽基全市场指数（类中证全指 / 国证A指），第四源独立确认。**

依据对撞四铁律：

1. **相关性仅生成候选、不定案（铁律#5）**：tx[56] 与 β_中证全指 Pearson=0.991、Spearman=0.988，构成**极强候选**，但非逐股数值精确相等（max|resid|=0.155、斜率 1.066≠1、截距 0.271≠0），**不升 L1 定案**。
2. **第四源独立确认**：前 3 轮（09-01 fuyao 无 Beta 端点、09-02 存在性、09-03 等权代理 Pearson 0.908）仅能证「Beta 族高置信」；本轮引入**完全独立的 TDX K线第四源**，且**定位出基准类别（宽基全市场）与近似变换（≈1.0× + 0.27 截距）**，证据强度由「猜想级」提升至「身份确认级」。
3. **缺口可完全解释**：残差与截距源于（a）腾讯 Beta 窗口/基准口径非同日同窗（本锚为 259 日 TDX 前复权，腾讯为自身滚动窗口）；（b）指数前复权/不复权与回归方法（简单收益 vs 对数收益）差异。此类口径差在「相关性证据」框架内属预期内，不构成反证。

**定级：维持「Beta 族·高置信」，并将置信由「09-03 等权代理 Pearson 0.908（基准未知）」升级为「第四源 TDX K线 β_中证全指 Pearson 0.991（基准类别已定位为宽基全市场指数）」。不强行 L1。**

> 升 L1 的唯一路径：取得腾讯官方字段表（确认其 Beta 基准=中证全指/国证A指 及滚动窗口），或未来取「同窗口同基准」第三方 Beta 做逐股精确对撞。当前证据已足以在项目中以「Beta（宽基全市场）」语义使用 tx[56]，标注置信来源。
