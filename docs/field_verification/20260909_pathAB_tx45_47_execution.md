## 2. 腾讯 qt.gtimg.cn 实时同源数值自洽（替代数值佐证）

> 背景：TDX MCP 会话失效，无法直接取 Zsz/ZTPrice 实时值。改用可达的腾讯 `qt.gtimg.cn`（与 `raw_tencent` 同源、部分同构契约）做**字段身份自洽**校验——确认 `raw_tencent` 的 tx[45]/tx[47] 读的是正确字段，且量级/单位与公开 qt 下标一致。

### 2.1 tx[45] = 总市值（vs qt[45]=总市值）

- 样本：20 股（raw_tencent 20260908，`docs/field_verification/20260908/raw_tencent.json`）。
- 比对：raw_tx45 vs qt[45](总市值, 亿)，并额外取 qt[44](流通市值) 排除"tx[45] 实为流通市值"误判。
- 结果：
  - 18/18 非北交股 raw_tx45 与 qt[45](总市值) **同量级对齐**（比值 0.99~1.10）。
  - 对 2 只"近全流通"股（002827、688426）脚本误标"流通市值疑"——经核为 `总≈流` + 09-08 快照 vs 09-09 实时价格位移噪声（raw 与 qt44/qt45 差均 <1%），**非真实误判**；其余 16 只 raw 与 qt45 距离均 ≤ 与 qt44 距离 → 确为总市值。
  - 北交 920118/920508：qt 无对应数据，单列，不计入通过率（与规划风险备注一致）。
- 比值偏差来源：总市值=现价×总股本，**价格相关**；raw 为 09-08 快照、qt 为 09-09 实时，单日价格位移致比值非 1。偏差幅度（最大 300788 1.10）与个股波动一致，结构性证明 raw_tx45 即"总市值"量级字段。

### 2.2 tx[47] = 涨停价（vs qt 中 prev_close×板块幅度 同值下标）

- 方法：在每只股的 qt 全下标中搜索 = `昨收[4] × 板块幅度(1.10/1.20/1.30)` 的下标，定位到 **qt[47]**。
- 结果：
  - 18/18 非北交股均能在 qt 中定位到与 `prev_close×板幅` 同值下标（qt[47]）。
  - **7/18 精确一致**（差 ≤0.08）：300031、600675、601288、688327、688426、688500、688553。
  - **11/18 存在偏差**（最大 002827 +7.59、600519 +7.38）：偏差可由"raw 为 09-08 快照（涨停价基=09-07 收）vs qt 为 09-09 实时（涨停价基=09-08 收）"的**基准日错位**完整解释——涨停价=上一交易日收盘×幅度，基日不同则价不同，属预期结构，反证 tx[47] 确为涨停价（否则不会随 prev_close 基日漂移）。
- 结构判读：偏差方向/量级与"基日错位"模型吻合 → tx[47]=涨停价 身份坐实。
