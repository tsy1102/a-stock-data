> 用户问："厂商字段表索取清单"——但该清单用户手上没有，要求通过公开网络核查是否存在。
> 结论：**存在**，分"官方发布"与"社区反向工程"两级；但均非本项目 `raw_tencent.json` 专属 87 字段契约，需对齐映射后方可定案。

## 2. 各厂商字段表明细

### 2.1 通达信（官方，最权威）
- 来源：`help.tdx.com.cn/quant/docs`（通达信官方量化 API 帮助中心）
- `get_more_info(stock_code, field_list)` 返回**命名字段**（节选实测）：
  `ZTPrice`=涨停价, `DTPrice`=跌停价, `Zsz`=总市值(亿), `Ltsz`=流通市值(亿),
  `fHSL`=换手率, `Wtb`=委比, `Zjl`=主买净额(万元), `Zjl_HB`=主力净流入(万元),
  `TPFlag`=停牌标识, `fLianB`=量比, `Fzhsl`=分钟换手率, `FzAmo`=2分钟金额(万元), `OpenAmo`=开盘金额(万元)…
- 公式函数 `DYNAINFO(N)`：`(3)`前收 `(4)`开盘 `(5)`最高 `(6)`最低 `(7)`现价 `(8)`总量 `(9)`现量 `(10)`总金额
- L2 共享内存结构（社区文档）：最新价@0x08、昨收@0x0C、买一价@0x10、买一量@0x14、卖一价@0x18…
- **对本项目价值**：`ZTPrice/DTPrice/Zsz/Ltsz/Zjl_HB` 等命名可直接交叉佐证
  `tx[45]`(总市值)/`tx[47]`(涨停价)/`tx[7-8]`(内外盘) 语义——是目前**唯一官方级**交叉源。

### 2.2 腾讯 qt.gtimg.cn（社区反向工程，非官方）
- 接口：`http://qt.gtimg.cn/q=sh600000`，返回 `v_代码="字段0~字段1~..."`（~ 分隔，GBK 编码）
- 社区解析表（cnblogs/soarowl、github/Flying9001、gitee/summerrain、xxmr.cn）核心下标：
  `3`=最新价 `4`=昨收 `5`=今开 `6`=总成交量(手) `7`=外盘 `8`=内盘 `30`=时间
  `31`=涨跌额 `32`=涨跌幅 `33`=最高 `34`=最低 `35`=最新价/总成交量(手)/总成交额(元)组合
  `37`=成交额(万元) `38`=换手率 `39`=市盈率TTM `44`=振幅 `45`=流通市值(亿) `46`=总市值(亿) `48`=PB
- **关键印证**：
  - 下标 `7`=外盘、`8`=内盘 与本项目 `tx[7]/tx[8]` **完全对齐**；
  - 下标 `35` 组合表明"均价=成交额÷成交量"须**服务端自算**——与 `tx[51]` 第四源 VWAP 定案一致（见 `20260909_vwap_extension.md`）。
- **局限**：公开表仅覆盖 0~59；末端拓展字段（市值/估值/资金）不同版本可能微调。

### 2.3 东方财富 push2（社区反向工程，非官方）
- 接口：`push2.eastmoney.com/api/qt/stock/get?fields=f43,f44,...`
- 社区解析：`f43`=最新价 `f44`=最高/昨收 `f46`=开盘 `f45`=最低 `f47`=成交量(手)
  `f48`=成交额(元) `f49`=PE-TTM `f50`=PB `f57`=代码 `f58`=名称 `f60`=备用昨收
  `f116`=总市值 `f117`=流通市值 `f168`=换手率
- **对本项目价值**：本项目 `fN` 族（f162/f163/f164 等）即东财 `f` 编号方案，**直接对应**；
  可补全 fN 官方级语义。**注意"同号异义"陷阱**：主域 `f164`=pe_ttm，而 `ulist.np` 端点 `f164`=近5日主力净流入（已踩坑，须端点字段映射防污染）。

### 2.4 新浪财经（社区反向工程）
- 接口：`hq.sinajs.cn/list=sh600000`，返回 `hq_str_代码="名称,今开,昨收,当前价,最高,最低,买一,卖一,成交量(股),成交额(元),..."`
- 另一套下标字段，可作腾讯/东财的交叉参考。

## 3. 与本项目字段的映射价值（已可定案/可强化的源）

| 项目字段 | 公开表佐证源 | 说明 |
|---|---|---|
| `tx[7]`/`tx[8]` 内外盘 | 腾讯 qt 下标 7/8 | 社区表与项目完全对齐 |
| `tx[45]` 总市值 | 通达信 `Zsz` / 东财 `f116` | 官方+社区双重交叉 |
| `tx[47]` 涨停价 | 通达信 `ZTPrice` | 官方命名交叉 |
| `tx[51]` 均价 | 腾讯 qt 下标 35 组合(额/量自算) | 印证"服务端计算"判断 |
| `fN` 估值/市值族 | 东财 push2 `f` 编号 | 直接对应，可补语义 |

## 4. 索取清单（仍需向厂商/社区补全的缺口）

即便公开表存在，以下仍为本项目"定案 L1"的缺口，需主动索取或对齐：

1. **腾讯 `raw_tencent` 专属 87 字段官方契约**：公开 qt.gtimg.cn 仅 0~59，项目扩展字段
   （含 `tx[56]` Beta 基准/窗口、`tx[85]` 价格类、`tx[29]`/`tx[83]` 占位符）无公开定义 →
   需腾讯行情字段官方文档或反推对齐表。
2. **腾讯 qt 完整拓展字段（>59）定义**：末端资金流/估值字段的官方说明。
3. **东方财富 `ulist.np` 多日资金流字段官方定义**：`f62/f66/f72/f137/f140/f143` 跨端点同号异义
   需官方端点字段映射（防污染）。
4. **北交所（920xxx）专属字段表**：北交所字段缺失（`tx[85]`=0、f85 流通股本缺失）需北交所行情字段契约。
5. **通达信 L2/十档/逐笔委托完整字段表**：当前官方仅有 `get_more_info` 摘要级，L2 结构多为社区文档，缺官方完整偏移/字段清单。

## 5. 风险提示

- 社区反向工程表**非厂商官方发布**，末端拓展字段可能随版本漂移；核心字段（价/量/五档/涨跌）长期稳定。
- 本项目 `raw_tencent` 与公开 `qt.gtimg.cn` **schema 不完全对齐**（字段数、下标偏移不同），引用时须核实下标而非直接套用。
- 定案 L1 仍以"同源精确对撞"或"厂商官方字段表"为唯一终止器；公开社区表可作强佐证，但须标注来源与版本。
