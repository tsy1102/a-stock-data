## 路径 A：`tx[45]` 总市值 — 通达信官方 `Zsz` 交叉佐证

**现状**：`field_meta` 已定 `tx[45]=总市值(亿元)`，L1 经 fuyao `float_market_cap×(总股本/流通股本)÷1e8` 数值精确锚定。

**交叉源**：通达信官方 `get_more_info` 返回 `Zsz=总市值(亿)`（中央化表 §1，OFFICIAL 高置信）。

**验证步骤**：
1. **定位可达通道**：确认 通达信官方 `get_more_info` 在本环境的取数通道——优先 `mcp__tdx-connector` 的 deep-info 类工具，或运行时 `easy_tdx` 若暴露 `get_more_info`；记录通道与单位（官方为"亿"）。
2. **取样**：取 20 股样本（覆盖沪/深/双创/北交；北交 `tx[45]` 单独标注，因北交字段可能缺失）。
3. **双轴比对**：
   - 语义轴：`Zsz` 命名=总市值 ⟺ `tx[45]` 命名=总市值 → 语义双官方确认。
   - 数值轴：`Zsz(通达信,亿)` vs `tx[45](亿元)` 逐股比值，要求 `|1−比值| ≤ 1e-3`（单位同为亿）≥ 18/20。
4. **验收**：语义+数值双轴通过 → 升级为"**双官方 L1**（fuyao + 通达信命名表）"；在 `field_dict` 加注"通达信 Zsz 官方交叉确认"。

**前置依赖**：步骤 1 通道可用（若 TDX MCP/easy_tdx 均无 `get_more_info`，则退化为"仅 fuyao L1 + 通达信命名语义佐证"，不阻断现有 L1）。

## 路径 C：`tx[56]` Beta 基准窗口 — 腾讯 raw_tencent 87 字段契约（**公开不可达**）

**现状**：round13 第四源（TDX K线独立重算 β_中证全指）已确认 `tx[56]`=Beta、基准类别=**宽基全市场指数**（Pearson 0.991 / R² 0.982 / slope 1.066 / LOO-min 0.987），但残差(max 0.155)/斜率(≠1)/截距(≠0)使其**按铁律#5 停留 L4 身份确认**。

**规划交叉源**：用户设想的"腾讯 raw_tencent 专属 87 字段契约"。

**可达性核查结论（本轮 + 既往检索）**：
- 公开网络**不存在** raw_tencent 87 字段官方契约。可获取的腾讯侧资料仅为 `qt.gtimg.cn` 社区反向工程表（中央化表 §2），且 **qt 无 Beta 字段**（qt 仅基础行情+估值+市值，不含系统风险 Beta）。
- 故"借腾讯契约明确 Beta 基准窗口"在公开域**不可行**。

**验证路径（退而求其次，边界明确）**：
1. **确认契约缺失**：记录检索结论——无官方 87 字段表，qt 无 Beta → `tx[56]` 无法经公开源升 L1。
2. **窗口/基准收窄（已部分完成）**：round13 已定"宽基全市场指数类基准"；进一步可选——对 `β_沪深300 / β_中证全指 / β_国证A指` 三基准做斜率灵敏度扫描，定位腾讯最可能的精确基准（斜率→1 者优先），把"基准类别"收敛到具体指数，但**仍非 L1**（铁律#5）。
3. **L1 真路径（外部）**：须腾讯官方字段定义其 Beta 的 (a) 基准指数、(b) 滚动窗口长度（如 60/120/250 交易日）、(c) 收益率频率。该文档不公开 → 列为"**永久 L4 身份确认地板**"，除非官方契约出现。

**验收**：本轮交付"明确边界"——已知 `tx[56]` 为 Beta、基准=宽基全市场指数、滚动窗口；精确窗口长度与基准指数名**待官方契约**，当前不可定 L1。

## 路径 D：`tx[85]` 价格类精确语义 — 腾讯 qt[85] 实证比对

**现状**：`field_meta` 定 `tx[85]=价格类, L3`；2026-09-09 VWAP 扩展对撞证伪"均价"（slope 0.998/残差 max 0.54），残差轮廓吻合"近似当前价/最新价"，维持 L3。

**规划交叉源**：腾讯 `qt.gtimg.cn` 下标 85（中央化表 §2/§5 指出 raw_tencent 与 qt 为**部分同构 schema**：对齐下标 {7,8,29,45}，非对齐 {83}；故 `tx[85]` 是否=qt[85] 须实证，不可假设）。

**验证步骤**：
1. **同构性判别**：取 20 样本，提取 `raw_tencent[85]` 与同股 `qt.gtimg.cn[85]`；
   - 若逐股精确一致（或恒定线性）→ `tx[85]=qt[85]`，再据 qt[85] 群体语义（对茅台为空，提示或为某特定类型字段如"可转债/北交专属"或"盘后衍生"）定性；
   - 若 `qt[85]` 群体为空/稀疏 → 印证 raw_tencent 与 qt 非同构，`tx[85]` 为 raw_tencent 专有字段，qt 路线失效。
2. **残差结构再分析**：若 qt[85] 可得，与 `close/最新价` 做斜率+残差比对，确认是"当前价"还是"某派生价"。
3. **L1 可行性**：即便 qt[85] 比对成功，qt 为社区表，仅能升 L2~L3 结构确认；**L1 仍缺官方契约**（同路径 C 困境）。
4. **验收**：给出 `tx[85]` 的精确语义候选（如"最新价/现价类"）与置信层级（至多 L2~L3）；若 qt 路线失效，维持 L3 并注明"待腾讯官方字段契约"。

**前置依赖**：20 样本 raw_tencent 已采集（现有）；qt[85] 实盘抓取（已验证 qt.gtimg.cn 在本环境可达，见中央化表 §2 实测）。

   ├─ A: tx[45] 总市值 ─┐
