## 2. 非破坏性搬迁原则

1. **只移动、不删除**：被迁文本整段剪切至 `docs/field_verification/历史归档/<dated>.md`，主字典原位替换为**一行索引链接**（blockquote 风格，见 §4 模板）。
2. **git 分支 + 逐步提交**：每迁一块独立 commit，任一环节回归失败可 `git revert` 单块。
3. **归档目录隔离**：归档文件置于 `docs/field_verification/历史归档/`（**非** `docs/verify/`），避免触发 `verify_sync_check.py` HARD 1/2/3 的孤儿/断链判定。
4. **状态不丢**：任何"迁前才发现、仅存在于被迁段、且 §12.8.12e 尚未收录"的字段结论，必须先 port 进注册表再迁（见 §3 前置防护）。
