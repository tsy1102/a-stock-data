## 二、方法：K线 close-to-close 对撞

对 4 只有 K线缓存的锚股，以 `close[-1]`（2026-09-11 收盘价）为基准，分别向前取 N 日：

```
rN  = (close[-1] / close[-1-N] - 1) * 100      # N ∈ {5,10,20,60}
rYTD = (close[-1] / close[首根2026] - 1) * 100
```

与 `raw_ulist239.json` 中 `f109 / f160 / f110 / f24 / f25` 直接比对（ulist 阶段涨幅字段单位即 %，无需换算）。

## 五、后复权 artifact 说明

ulist 阶段涨幅采用**后复权**口径（除权除息后价格回填），故：

- **无分红窗口 / 无分红股**：raw K线 close-to-close == ulist 值，**逐位精确**（最干净校验：000568 5日/10日、002827 5/10/20/60日、300788 5/10/20日）。
- **窗口内含分红**：raw K线 < ulist（因为除权使 raw 收盘价被"压低"，后复权已回填），如 000568 20日 raw -17.66 vs ulist -13.38、YTD raw -37.60 vs ulist -33.33；600309 全窗口背离（近期除权）；300788 60日/YTD 略有背离。
- **结论稳健性**：即便只信"无分红精确吻合"子集，000568(5/10日)+002827(5/10/20/60日)+300788(5/10/20日) 已对 f109/f160/f110/f24 给出多股精确锚定；f25(YTD) 由 002827 近似 + 其余后复权量级一致性 corroborate。
