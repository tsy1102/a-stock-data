## 〇、方法与铁律（防误判首读）

- **解析**：从两锚抽取 `fXX → 中文标签`（按 `##` 小节标注端点空间），从字典抽取 `fXX → 状态(✅/⚠️)/描述/小节`；求交/求并后分类。
- **🔴 跨端点同号异义铁律（本碰撞的最高优先级约束）**：东财 `push2 stock/get` 与 `ulist.np` 复用同一套 `f` 编号但**语义不同**（如 push2 `f164=pe_ttm` ≠ ulist `f164=近5日主力净流入`）。**锚与字典的字段比较必须绑定端点空间**，否则必生类别错误。
- **判定规则**：
  - 锚标 `fXX` 且字典同号行已 ✅ → 互证（不改动）。
  - 锚标 `fXX` 且字典同号行 ⚠️/占位 → **提升候选**，但须先核验端点空间一致（同端点才提升）。
  - 字典 ⚠️ 且两锚均未标 → 真实天花板（本方法不可破）。
