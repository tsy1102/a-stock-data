## 1. 审计目标与三分类产出

执行后必须产出逐接口字段级清单，并按下述三分类：

- **A 类 · 已覆盖**：字段语义字典已有（经数值对撞或中文命名比对确认）。→ 仅作**新增交叉验证锚**，不新增注册行。
- **B 类 · 真新字段**：字典确实缺失（外部分析预判 GP06 陆股通持股 / GP27 人气排名 / GP39-40 涨停统计等，待实抓核实）。→ 走 sanctioned 登记管线。
- **C 类 · 市场聚合**：SC 系列为跨股聚合指标（涨停数/连板家数/新高新低），**非 per-stock 字段契约**。→ 单独立 `§12.x「市场宽度/情绪」`段（跨日聚合），不污染 per-stock 字段集。

## 2. 环境依赖与通道铁律

1. **采集通道 = 本地 tdxquant 插件**（用户 `C:\new_tdx64\PYPlugins\user\` 环境，需**通达信客户端在线登录**）。复用既有 `field_verify_tdxquant.py` 模板（见 `README.md:1535` / `field_dict.md:3671`）。
2. **不走 TDX 云 MCP**：云 MCP 无 GP/SC/GO/FN/BK 入口。
3. **依赖安装**：本沙箱 `tdxquant` 缺失，步骤 B 需先确认用户环境已装，或授权后 `pip install tdxquant`（建议用项目受管 venv，勿污染系统 Python）。
4. **方法名不假设**：五接口具体方法签名（如 `get_gp(code, gp_id)`）以实抓时 `dir(TdxFinance)` 枚举 + 官方文档为准；本方案不固化未验证的方法名/参数字典。

## 4. 采样设计

- **个股样本**：沿用黄金锚/对撞既有 12–20 只（600519 / 601288 / 000568 / 000001 / 300750 / 002827 / 688553 等），覆盖主板/创业板/科创板。
- **北交所 920 段**：tdxquant 已知无返回（`field_dict.md:523`），样本需标注、不计入覆盖率分母。
- **市场级样本（SC）**：全市场快照 1 次 + **≥3 独立采集日**（满足对撞四铁律 #4：≥3 日复核稳定性）。
- **单位对齐**：get_more_info 单位为"亿/万元/万股"，五接口单位各异；比对前**必须统一换算**（避免量级误判，重现 118 陷阱）。

## 10. 决策更新（2026-09-14）：放弃 GP/SC/GO/FN/BK 接口面

**用户裁定**：TdxQuant 的 `func` 接口（`get_gp/get_sc/get_go/get_fn/get_bk`）需安装**通达信客户端 App** 才能取数（pip 仅装库体不行，依赖 App 的 `func_*.cfg` 与本地数据文件）。项目定位"**轻量优先**"，故**放弃该接口面**——步骤 B 不执行，本方案止步于 A（规划）。

**影响评估**：
- 不新增任何 TdxQuant `func` 接口为源/锚，不违反轻量约束；不进运行时取数路径（沿用 TDX 双层铁律，运行时仍=`easy_tdx`、云 MCP 仅参考）。
- 现有 `get_more_info` 88 字段（§12.9.1）经 `easy_tdx` 本地 TCP 通道交付、**无需 App**，保持现状。
- 外部分析点名的"高价值字段"经 §5 核对多数已在字典定案，真实新增价值本就有限；放弃后**字段覆盖零净损失**。

**轻量替代源映射**（改由已有的轻量源提供，无需装 App）：

| 原五接口欲取字段 | 轻量替代源（项目已覆盖/可覆盖） | 字典位置 |
|---|---|---|
| GP06 陆股通持股 / 北向 | 北向持仓（eastmoney / akshare `stock_hsgt_*`） | §12.x HSGT / 北向段 |
| GP27 人气排名 | 东方财富 / 同花顺 人气榜（lightweight HTTP） | 若确有缺口走 sanctioned 管线 |
| GP39-40 涨停统计 / SC 涨停数·连板家数·新高新低 | 东方财富 涨停板 / 跌停板 / 市场宽度（eastmoney `stock_lhb` / limit 数据） | 市场宽度段（如确需，另立 §12.x「市场宽度」） |
| GO3~25 一致预期 | 同花顺 `get_eps_forecast` / 东财一致预期 | L2042 / 2173 / 2631 |

**结论**：放弃五接口面后字段覆盖零净损失；若后续确需"市场宽度/情绪"类跨日聚合数据，优先走 eastmoney 轻量接口，而非安装 TDX App。
