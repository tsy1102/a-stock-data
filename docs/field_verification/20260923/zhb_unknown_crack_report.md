## 2. `stat.unknown_2`（Col[2]）— ⚠️ 候选（未定案）

- **分布**：7668 股，范围 −0.913 ~ +5.186，均值 0.90，std 0.81，5119 unique；3.7% 为负。
- **相关性**：与 tdxstat/tdxstat2 全列**零/弱相关**，多列线性回归 **R²=0.50**，单变量最大 \|r\|=0.365（年线 +0.365 / YTD +0.362 / 60日 −0.350 / 成交额 +0.27）。→ 系**独立指标**，非已知列线性副本。
- **候选义 A（量比−1）**：个股量级吻合——银行股（000001/600036/600900）为负（量比<1 成交清淡），半导体(688981=+2.29)、面板(000725=+1.34) 为正（放量）。
- **验证阻塞**：探针源**日期错位**（zhb 缓存=20260922，tencent 探针=20260923，数组内 `ts=20260923161450`）→ 同日量比无法闭环；collide 引擎仅 `zhb.full↔zhb.stat` 内部配对，未与外部源成功配对。
- **结论**：候选义=量比−1 或 动量/回撤复合因子；**须同日量比源数值闭环后方可晋级 L1**。

## 4. 补充复核（2026-09-23）：unknown_2 = 量比-1 已被同日量比源证伪

- **方法**：取 `cache/kline/` 全市场日K线 pickle（含 2026-09-22 收盘，1007 只），对每只股票计算
  `量比 = v_20260922 / mean(v_前5交易日)`；与 `tdxstat.cfg` Col[2] 同码比对，共 **1000** 匹配股。
- **结果**：`corr(unknown_2, 量比) = -0.0807`、`corr(unknown_2, 量比-1) = -0.0807`（几乎零相关）；
  回归 `unknown_2 ~ -0.064*量比 + 1.349` 残差中位 0.70；最佳单因子拟合 `unknown_2 = 0.382*(量比-1)` 残差中位 1.36。
- **结论**：**证伪** 上一轮候选「unknown_2 = 量比-1」。unknown_2 真义仍待定，维持 ⚠️ 候选。
  已立护栏 **R9**（`scripts/collision_rules.py`）固化该证伪结论，防止后续自动对撞再次提案。
