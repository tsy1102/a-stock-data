## 1. tdxstat `[22]` —— 短期/中期/长期形态三档【L1 铁证】

### 1.1 关键修正：`[22]` 不是单值，而是"去前导零的 6 位复合码"

此前一度误判为"6 位形态码"，本轮严格复核发现：**文件中以整数存储，前导零被剥离**。

```
原始值        补零后        拆解
'21109'   →  '021109'  →  02 | 11 | 09
'141301'  →  '141301'  →  14 | 13 | 01
'70900'   →  '070900'  →  07 | 09 | 00
'81101'   →  '081101'  →  08 | 11 | 01
```

### 1.2 决定性验证

| 验证 | 结果 |
|---|---|
| **V1 值域** | 补零后三档全部落在 **00–14**：越界 **0 / 312,768 = 0.000000** |
| **V2 数据长度相关性** | 档3=00 的 17,071 样本中，日线长度 **<240 根占 99.78%**（<250 根占 100%，最大 242）<br>档2=00 的 6,283 样本中，日线长度 **<120 根占 98.92%**（<130 根占 100%，最大 127） |
| **V3 取值数** | 档1: 14 个（01–14，无 00）；档2/档3: 各 15 个（00–14） |
| **空值** | 7,717 / 320,485 = 2.41%（无形态数据） |

### 1.3 与官方定义吻合

`ihelp.dat #FUNC_ABCol`：
- L92 **短期形态**：对近 **60 天**历史行情走势进行形态判断
- L93 **中期形态**：近 **120 天**
- L94 **长期形态**：近 **240–500 天**

**档3=00 ⇔ 历史<240 根、档2=00 ⇔ 历史<120 根** —— 与 60/120/240 三档周期**逐一对齐**，且 0 违规。

## 2. tdxstat `[26]` —— 年涨停天 YearZTDay【L1】

### 2.1 官方定义

`ihelp.dat #FUNC_ABCol` L64：**年涨停天：近一年内的涨停次数（不包括未开板的涨停）**。

**"未开板"的准确含义**：`ihelp.dat #FUNC_TDXStatZS` L432 给出同源措辞——"板块指数中的涨停数统计**不包括未开板次新股**"。故"未开板的涨停"= **新股上市初期的连续一字板**，**不是**排除全部一字板。

**证伪检验**（本脚本 `diag_u26_sealed.py`）：

| 模式 | 全量 | \|Δ\|≤1 |
|---|---|---|
| all（基线） | **0.9068** | 0.9839 |
| no_yizi（排除全部一字板） | 0.8078 | 0.9340 |
| no_openlimit（排除开盘即封） | 0.7522 | 0.8892 |
| no_ipo（排除序列开头连续涨停段） | 0.9068 | 0.9839 |

→ **排除一字板显著变差**，证明 TDX **统计一字板**；"未开板"只能指次新股段。IPO 段假设因 800 根缓存非上市起点而无法直接检验（留待后续）。

**定案：`[26]` = 年涨停天 YearZTDay，窗口 = 个股自身最近 243 个交易日，含一字板。全市场精确命中 90.77%、±1 命中 98.53%，满足铁律②"全市场 ≥90% 即 L1"。L1。**

## 6. tdxstat `[2]` —— 贝塔系数(60日)【L2】

### 6.1 官方定义

`ihelp.dat #FUNC_ABCol` L63：**贝塔系数：个股相对于大盘的波动表现（最近 60 天统计，深市大盘对应深证成指，沪市对应上证指数）……0.5 为低风险，1.0 平均，2.0 高风险**。

`ihelp.dat #FUNC_HGFX`（回归分析，L778–805）：**β = 线性回归斜率**；Y = 个股，X = 大盘指数；数据支持"N 倍收盘价/最高价/最低价/开盘价"序列；计算方式可选「按数值」或「**按百分比**」（取变动幅度值）。

| 变体 | 命中率 | 比值中位 |
|---|---|---|

| 对数收益率 + 前复权 + W=60 | 0.0022 | 0.996062 |
| 均价口径 W=60 | 0.0000 | 2.153900 |
| 价格水平 W=60 | 0.0000 | 88.594424 |
| W=59 / W=61 | 0.0038 / 0.0039 | — |
| W=120 / W=250 | 0.0002 / 0.0001 | — |

**只有"算术收益率 + 前复权收盘 + 60 日窗口"能命中**，且**比值中位 = 1.000014 ≈ 1**。

### 6.3 收益率复权口径实证

用 `tdxstat[6]`（当日涨跌幅）判定除权日口径，63 个除权样本：

| 口径 | 一致数 |
|---|---|
| **前复权一致** | **59** |
| 不复权一致 | 0 |
| 两者都不一致 | 4 |

（例：000002 qfq −4.0816 / raw −3.0612 / tdx[6] −4.0800 → **QFQ**；301689 qfq 20.0000 / raw 19.3705 / tdx 20.0000 → **QFQ**）

→ **TDX 的涨跌幅按"除权调整后口径"计算**（与交易所"除权后昨收"一致）。

### 6.4 残差结构

逐股比值恒定性：**A 类 77 只比值恒等 1**；**B 类 845 只比值恒定但 ≠1（CV<2%）**；**C 类 162 只比值漂移（CV≥2%）**。B 类集中于**低 β 高股息蓝筹**（603663 0.7226、601658 1.1771、600036 1.1234、601328 1.0817、601988 1.0622）；C 类为 β≈0 的符号翻转股（600016 −0.3748 CV 47.7、601169 −0.6061）。

→ **逐股恒定偏移 = 指数基准差异**（未用真实上证/深证指数序列回归），**不是口径错误**。

**定案：`[2]` = 贝塔系数(60日)。口径已唯一确定（算术收益率/前复权/60 日），比值中位 = 1.0000。维持 L2；升 L1 需引入真实指数日线做回归复现（本轮指数抓取被腾讯 fqkline 限流阻断）。**
