# ELTDX 相邻财务字段候选复核（2026-11-11）

> 后续定案：本文第 26 行列出的两条 `finance_batch[]` 股本槽位已按 E3 来源内实证定案，见[裁决记录](adjudications/20261111_eltdx_share_slots_empirical_semantics.md)。`zhu_ying_li_run_raw_float` 后经四家公司 2026Q3 报表核对，确认该 ELTDX 路径的实测值对应“营业成本”；来源标签冲突与边界见[独立裁决记录](adjudications/20261111_eltdx_zhu_ying_li_run_empirical_semantics.md)。

## 方法与范围

本记录继续按“名称先给候选、证据再检验”的顺序处理 `TDX-eltdx(适配层)` 的财务路径。拼音候选不由数值倒推；`raw_float` 只说明数值表示方式。项目固定 `eltdx==3.3.2`，采集路径为 `scripts/capture_tcp_collectors.py::collect_eltdx` → `client.corporate.finance_batch(..., include_raw=True)` → `raw_eltdx.json` 中 `stocks.<code>.finance_batch[0]`。

本轮只确认 ELTDX 这一完整来源路径的来源内语义与单位，不建立 TDX、ZHB、东财或发行人报表之间的字段映射。`raw_eltdx.json` 的采集目录日为 2026-11-10；逐股 `updated_date` 为来源返回的财务更新日，财务值按公告所列 2026Q3 报告期核验，不把采集自然日当成报表数据期。
