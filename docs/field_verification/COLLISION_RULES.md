## 一、对撞四铁律（硬阈值）

| # | 铁律 | 阈值 / 判定 |
|:--|:--|:--|
| 1 | 精度对齐 | |a−b| ≤ max(ulp_a, ulp_b)（舍入感知）；整数/枚举降级为严格 1e-9 |
| 2 | 命中率分层 | 每采样日 ≥18/20 且可解释 → **L1 定案**；8~17 → L4 候选（存疑） |
| 3 | 比值族 | CV≤0.0001 且比值∈(10, 100, 1000, 10000) → L1-U 单位换算定案 |
| 4 | 多日复核 | ≥3 个独立采集日重复方可定案；单日 20 股快照不够 |
| 5 | 相关性 | 仅 Pearson+Spearman 同号且 |Spearman|≥0.6 且留一法不翻号 → 候选，绝不定案 |

## 二、定案状态机 L1~L4

| 层级 | 名称 | 升格来源 |
|:--|:--|:--|
| L1 | 定案（最高置信） | 多源对撞实锤，四铁律全满足 |
| L2 | 官方/强锚定 | fuyao 官方三表锚 / TDX 官方命名语义终止器 |

## 三、不对撞（跳过）规则

- 已 L1 定案字段：移出 FOCUS，不再主攻；仅进全历史复核的回归保护池
- 标识符字段（market/code/date/name/tx[1..3]）：排除出数值对撞目标，防 false L1
- 常量占位字段（f106 恒100 / f123..f134 恒0）：无信息量，登记为占位而非未知语义
- 20 股 ZHB 锚巧合陷阱：任何新映射若与已确立映射矛盾，判为巧合而非发现，须打印原数据人工核实
- 相关性（Pearson/Spearman）只生成候选，绝不定案
- 单日 20 股快照不足以定案，须 ≥3 个独立采集日重复

## 四、对撞 / 不降解撞的判定边界

- **主攻对撞（crack）**：仅对 `FOCUS` 内未定案的 residual unknowns 跑；已 **L1** 字段从攻击目标移除。
- **全历史复核 / 再确认（re-validation）**：全量扫描会顺带扫到已定案字段，结果标注「再确认 / 强化现有结论，未改动语义」，作为回归保护。
- **锁定点 = 升到 L1**：该字段转为对齐锚 / 真值参考，用于破解其他未知字段时的核对与跨源一致性校验。
- **双向可修正**：L1 遇矛盾新证据可降级或重议（如 tx[85] 均价候选因锚仅 3/20 回退 L3；tdxstat[31] 对撞东财仅 77% 匹配降级）。
