# ELTDX 0x0010 财务字段来源契约核验（2026-11-09）

## 定案范围

本批只核验运行时来源 `TDX-eltdx(适配层)`（`source_lineage.json` 中别名 `eltdx`）的五个精确字段路径：

- `eps_raw`
- `liu_tong_gu_ben_raw_float`
- `zong_gu_ben_raw_float`
- `zong_zi_chan_raw_float`
- `jing_li_run_raw_float`

这些字段由 `scripts/capture_tcp_collectors.py::collect_eltdx` 调用 `client.corporate.finance_batch(ec, include_raw=True)` 采集，再由 `_jfy` 序列化到 `raw_eltdx.json` 的 `stocks.<code>.finance_batch[0]`。本结论按 `(source, 完整 code path)` 登记；没有把 ELTDX 与 TDX 直连字段建立映射。

## 接口契约

项目依赖固定为 `eltdx==3.3.2`。该版本文档将 `finance_batch` 标为 TDX `0x0010` 财务基础信息接口，并明确列出以下模型字段及单位：

| 完整路径 | 定案含义 | 单位 | v3.3.2 契约 |
|---|---|---|---|
| `eps_raw` | 每股收益原始值 | 元/股 | 每股收益值；文档未区分基本/稀释 EPS |
| `liu_tong_gu_ben_raw_float` | 流通股本原始值 | 万股 | 原始万股口径 |
| `zong_gu_ben_raw_float` | 总股本原始值 | 万股 | 原始万股口径 |
| `zong_zi_chan_raw_float` | 总资产原始值 | 千元 | 原始千元口径 |
| `jing_li_run_raw_float` | 净利润原始值 | 千元 | 原始千元口径 |

接口文档另列四个换算属性：流通股本和总股本分别乘 10,000 得股数；总资产和净利润分别乘 1,000 得元。本批未把这些派生属性登记到 ELTDX 的未观察路径，也未把历史参考文档中的同名 TDX 路径自动视作本适配器路径。

## 保留样本对撞

核对了 `docs/field_verification/20261105/` 与 `20261106/` 下的 `raw_eltdx.json`、`raw_push2.json`、`raw_zhb.json`。两日各有 20 只共同股票：

- `eps_raw` 与同日 ZHB `tipinfo.eps` 的绝对差在 20/20 个样本中不超过 0.01，最大为 0.005。ZHB 以两位小数保存，故将这层结果作为舍入近似证据，不声称逐值完全相等。
- `liu_tong_gu_ben_raw_float × 10,000` 与东财 `f85`，以及 `zong_gu_ben_raw_float × 10,000` 与东财 `f84`，在两日各 20/20 个样本中相对误差均不超过 `1e-6`。最大相对误差分别为 `7.56e-7` 和 `1.51e-7`，与 TDX 浮点原始值的量化精度一致。
- 两日样本的 `report_period` 均为 `20260930`；这些对撞验证的是同一季度财务快照，不把采集日误当作财报期。

上述 ZHB 与东财数据仅作独立佐证；本批没有新增跨源映射。

## 边界与未定案项

- EPS 样本对应报告期累计值（当前为 2026 年前三季度），接口文档未声明该字段区分基本或稀释 EPS；两类值在这三家公司本期报告中相同，因此不进一步细分。
- 600309 的 `updated_date` 为 2026-10-26，而法定季报披露日为 2026-10-27。该字段不能据此当作公告发布日期；本批只用公告金额核验语义和单位。
- 历史字段参考中的 §12.13.2 仍关联到 `TDX(双命名源)`，而契约原文和当前采集路径属于 ELTDX。类似名字的 TDX 直连路径及未观察到的派生属性留待单独做来源归属审计，不由本次结果覆盖。
