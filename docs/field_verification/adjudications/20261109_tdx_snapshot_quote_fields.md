# TDX 实时行情快照基础字段定案（2026-11-09）

## 定案范围

依据通达信官方 `get_market_snapshot_batch` 返回字段表，核对与注册表 `(source, code)` 完全一致且此前未验证的 21 个字段。官方字段表将这些返回值的接口类型标为 `str`。

本结论只确认 TDX 字段名称和官方语义，不表示项目生产代码调用了该接口，也不建立这些字段到项目业务 canonical 字段的映射。字段单位只有在官方描述明确时登记；其他保留为未注明。`Inside` / `Outside` 对板块指数有不同含义，`Zangsu` 的计算窗口未披露。
