# ZHB `tdxstat.cfg` 账务字段元数据纠正

核验日期：2026-11-09。

## 定案

| 完整 code path | 旧登记 | 更正后 | 2026-11-06 ZHB 样本与公开财报 |
|---|---|---|---|
| `ZHB-tdxstat::[25]` / `pre_receive_zj` | 预收资金（万元） | 合同负债（万元） | 万科 000002 为 6588884.44；2026 年三季报合同负债 65888844417.49 元 ÷ 10,000 = 6588884.441749 万元（四舍五入后与样本一致） |
| `ZHB-tdxstat::[34]` / `other_qy_jzc` | 其他权益净资产（元） | 其他权益工具（万元） | 平安银行 000001 为 8000000.00；2026 年三季报其他权益工具 80000 百万元 = 8000000 万元 |

样本来自文件名数据日为 `20261106` 的保留归档 `cache/zhb/zhb_20261106.zip`。解析器 `_parse_tdxstat` 按固定位置读取 `[25]` 和 `[34]`，值为 `float`，没有单位换算。保留期逐日扫描还显示，平安银行 `[34]` 在 15 个日期均为 8,000,000.00；万科 `[25]` 于 2026-10-29 起变为 6,588,884.44，与三季报披露时间相符。

## 影响边界

- 只纠正字段语义和单位元数据；不改列索引、返回键、数值、缓存键或序列化。
- `pre_receive_zj` 与 `other_qy_jzc` 是历史兼容键，保留原名以避免改变解析结果结构。
- 不创建 ZHB 与 TDX `PreReceiveZJ` / `OtherQYJzc` 的跨源逐值映射。
- 注册表按 `(source, 完整 code path)` 区分来源。更正后，`[34]` 与腾讯同编号路径的含义差异会继续以逐源记录呈现，聚合字段视图应显示冲突，不得把同号列合并成同一语义。

公开网页与计算记录见 [`public_web/20261109_tdx_more_info_fields.md`](public_web/20261109_tdx_more_info_fields.md)。机器可读裁决见 [`20261109_zhb_accounting_metadata_corrections.json`](20261109_zhb_accounting_metadata_corrections.json)。
