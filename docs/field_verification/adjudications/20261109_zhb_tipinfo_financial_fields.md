# ZHB tipinfo 报告期、累计 EPS 与预约披露日定案

## 范围与方法

本轮只核查 `ZHB-tipinfo` 的 `report_period`、`eps`、`disclose_date` 及原始列 `[2]`、`[3]`、`[4]`。只读取数据保留起点 2026-10-15 及之后的 15 个日期化 ZHB 包；不回补更早历史数据。

项目解析器将 `tipinfo.dat` 的 `[2]`、`[3]`、`[4]` 分别转换为 `report_period`、`eps`、`disclose_date`。逐包按股票代码读取每条原始记录并与解析结果对照，共 84,815 个股票日观察。报告期和日期字段按字符串逐字比较；EPS 将原始十进制文本与解析浮点值的十进制字符串表示做 `Decimal` 数值比较，不设容差。三组均为 84,815/84,815 一致、0 个不匹配。每个包的行数与 SHA-256 见 [`20261109_zhb_tipinfo_alias_audit.csv`](20261109_zhb_tipinfo_alias_audit.csv)；45 条代表行见 [`20261109_zhb_tipinfo_samples.csv`](20261109_zhb_tipinfo_samples.csv)。

## 定案

| 字段 | 定案含义 | 单位 | 证据与限制 |
|---|---|---|---|
| `[2]` / `report_period` | 财报报告期截止日 | `YYYYMMDD` | 15 个包的逐行解析对应；三只股票的 2026-06-30、2026-09-30 期末与发行人报告一致。 |
| `[3]` / `eps` | 报告期累计每股收益 | 元/股 | 三只股票在 2026-06-30、2026-09-30 的六个报告期样本与官方半年报、三季报年初至报告期末值逐一一致。ZHB 未标注基本、稀释或扣非子口径，样本值不能区分这些口径，故不作更细定案。 |
| `[4]` / `disclose_date` | 财报预约披露日 | `YYYYMMDD` | 三只股票的预约日与东方财富官方个股日历一致；两例预约日晚于实际公告日，且采集发生在公告后仍保留预约日，排除“实际披露日”解释。 |

公开网页、报告原件、报告期值和实际公告时间的逐项来源见 [`公开网页核验记录`](public_web/20261109_zhb_tipinfo_financial_fields.md)。

## 注册表影响

- 更新 3 条运行字段和 3 条原始列的含义/单位；对原有已验证原始列保留 `verified`，将决议来源改记为 `manual_public_data_semantic_adjudication`。
- 不新增跨源 `mappings`，也不把 ZHB `[3]` 直接映射到通达信 `FN1`。这轮只确认来源内字段的语义，不主张接口字段身份完全相同。
- 不改解析值、字段 key、报告期事件上下文、缓存键、序列化或来源路由。`report_period` 仍按现有代码进入 `report_date`。
- 将解析器注释从“实际披露日”修正为“预约披露日”，避免后续复核误用日期口径。

结构化决定见 [`20261109_zhb_tipinfo_financial_fields.json`](20261109_zhb_tipinfo_financial_fields.json)。
