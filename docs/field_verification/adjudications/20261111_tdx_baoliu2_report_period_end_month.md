# TDX `baoliu2` 报告期末月份的来源内实证定案

日期：2026-11-11。完整字段身份：`TDX(双命名源)::baoliu2`。结论仅适用于项目当前 `get_finance_info (0x0010)` 采集路径和本记录覆盖的 2026 年半年报、三季报样本。

## 定案

`baoliu2` 实测表示财务记录对应的**报告期末月份**，单位为月。本次保留样本中，值 `6` 对应截至 2026-06-30 的半年报记录，值 `9` 对应截至 2026-09-30 的三季报记录。其他月份、年份、历史协议版本及未来服务端行为均未据此推断。

此结论是来源内经验定案，不是通达信官方字段契约定案。项目既有字段表把该槽位记为“保留字段2”；这一标签来自协议逆向资料，而非找到的通达信官方逐字段说明。通达信官方量化文档中的 `get_financial_data` 是另一套按报告期筛选的接口，没有给出本项目 0x0010 `baoliu2` 的字段映射，因此保留该官方定义缺口，不把逆向资料冒称官方定义。

## 路径与样本

项目路径为 `core/tdx_client.py::tdx_get_finance_info` 读取 TDX 财务响应，`scripts/capture_tcp_collectors.py::collect_tdx` 将结果保存到 `raw_tdx.json#/stocks/<code>/finance_info/baoliu2`。用于审核的样本全部来自 2026-10-15 起的保留目录；没有读取更早的 raw 文件或 ZHB 缓存。

2026-10-15 至 2026-11-10 的 17 个采集目录共含 20 只股票的 340 条观测：`6` 出现 162 次，`9` 出现 178 次。20/20 股票都只发生一次 `6→9` 转换，没有反向转换、其他取值或未转换股票；每次取值变化都伴随该记录的 `updated_date` 更新。完整逐目录、逐股票审计表为 [`20261111_tdx_baoliu2_transition_audit.csv`](20261111_tdx_baoliu2_transition_audit.csv)，SHA-256：`E7F3D5308C913592FEA32F05CD4EA9C22EEA924C3BEC8CE22294FA4191C495AF`。

`updated_date` 只作为财务记录更新时点的辅助证据，未被当作采集运行日、目录目标数据日或报告期末日期。报告期由发行人正式报告确认。

## 旧标签与裁决边界

- 保留原始参考记录“保留字段2”作为协议资料标签，不改写历史来源材料；它不能覆盖当前采集路径上的 20/20 实测变化。
- 结论只解释当前来源路径中实际返回的 `6` 和 `9`。不声称知道年份、报告类型码、报告发布日期，也不把该字段当成来源 `as_of_date`。
- 不建立与其他来源的映射，不改动采集、解码、统一层、缓存或碰撞路由。
