# Eastmoney 资金流中单字段来源内语义复核

审阅日：2026-11-13。裁决范围为 `东财-push2(stock/get)::f144/f145/f146`、`东财-资金流(em_fund_flow)::f144/f145/f146` 和 `东财-ulist239(np/get)::f76/f77/f78` 九条精确来源路径。

## 定案

- `f144` / Ulist `f76`：中单流入/买入金额，规范名 `fund_mid_buy`，单位元。
- `f145` / Ulist `f77`：中单流出/卖出金额，规范名 `fund_mid_sell`，单位元。
- `f146` / Ulist `f78`：中单净流入金额，规范名 `fund_mid_today`，单位元；`f146=f144-f145`。

依据包括：东方财富 Ulist 官方个股资金流页面既有逐项核验、东方财富产品页对“中单”类别及流入/流出/净流入标签的呈现、项目对接口编号族的精确区分，以及 2026-10-15 之后保留期的 140 条逐股逐日同值样本和 140/140 算式复核。Ulist `em.ulist_np` 与 Push2/资金流 `em.stock_get` 是同一提供方的不同接口；结果只确认这几条精确路径之间的字段角色，不把接口重复数据视为不同提供方的独立证据，也不新增映射。

## 官方页面的字段角色

项目留存的 Ulist 官方网页核验记录 [`20260913_em_ulist_crack_round6.md`](../20260913_em_ulist_crack_round6.md) 记录了东方财富个股资金流页面（更新时间 2026-09-11 16:05）对五只股票的同日观察：`f76` 对应页面“中单流入”、`f77` 对应“中单流出”、`f78` 对应“中单净流入”；并且 `f78=f76-f77`。例如 000568 页面显示 `f76=1.9378亿`、`f77=1.4266亿`、`f78=5112.11万`，与当时记录的 Ulist 原值分别在展示精度内吻合。这里仅引用既存网页核验报告作为字段标签证据；本次新数值复核完全使用 2026-10-15 之后的保留 raw，没有读取更早 raw。

东方财富官方[个股资金流页面](https://data.eastmoney.com/zjlx/600519.html)展示实时成交分布中“类型/流入/流出”的超大单、大单、中单、小单分类，以及历史表中的主力、超大单、大单、中单、小单净流入列。官方[资金流 FAQ](https://emdesk.eastmoney.com/pc_activity/Pages/VIPTrade/pages/link/zjl.html)说明资金流是东方财富自身的逐笔/委托分类计算，交易所不发布其实时和盘后个股资金流。故释义只表达东方财富自身分类口径，不代表真实账户身份。

## 文档标签更正

`docs/verify/ulist_push2_align.md` 的配对路径本身仍成立，但四条净流入行的中文标签曾整体错移一档：`ulist f62→push2 f137` 应为主力净流入；`f66→f140` 应为超大单净流入；`f72→f143` 应为大单净流入；`f78→f146` 应为中单净流入。另将旧称“特大单”统一为东方财富页面标签“超大单”。以上更正由该表已有官方标签资料和本次 140 条逐日对齐支持，不改变字段代码或关系类型。

## 边界

官方未公开 `stock/get` 的 `f` 编号逐字段 API 字典；本结论是对精确来源路径的实证语义确认，不声称官网发布过代码表。类别阈值、服务端历史回填机制以及东方财富与其他提供方模型是否一致不在本批范围。没有新增 `mappings`；已有路径关系不凭短编号合并。
