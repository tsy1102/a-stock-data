# Push2 `stock/get::f103` 经营现金流 TTM 实证定案

核验日：2026-11-13。范围仅为 `(东财-push2(stock/get), f103)`；不将其他接口的 `f103` 或其他同名字段合并解释。

## 定义依据与采集路径

东方财富 `stock/get` 的公开字段代码表未找到 `f103` 的正式中文定义。本结论依据精确采集路径、同花顺金融数据 API 对现金流量表项目的中文释义，以及发行人定期报告的逐值核对建立；不把第三方字段表当成东方财富官方契约。

[`collect_push2()`](../../../scripts/capture_http_collectors.py) 将响应对象 `data` 原样存入 `stocks.<代码>.data`，未重命名或计算其中的 `f103`。采集数据路径为 `raw_push2.json:stocks[code].data.f103`；同一响应的 `f86` 是行情时间戳。`capture_field_probe.py` 归档时保留此原始响应。

同花顺金融数据 API 的[现金流量表接口文档](https://fuyao.aicubes.cn/docs/mcp/tools/get_a_share_financials_cash_flow_statements/)定义 `act_cash_flow_net` 为“经营活动产生的现金流量净额（原币元）”，接口返回合并现金流量表的多个报告期，并提供报告期、币种和披露时间。项目归档对应路径为 `raw_fuyao.json:stocks[code].financials.cashflow_q[]`，币种为 CNY。

## 公式与全样本结果

按现金流量表的年度累计口径计算：

```text
经营活动现金流量净额 TTM
= 上年全年经营活动现金流量净额
  + 本年最新报告期年初至今经营活动现金流量净额
  - 上年同期年初至今经营活动现金流量净额
```

基于每个数据日归档的 Push2 原始响应和 Fuyao 原始现金流报表，从原始文件重新计算全部样本。166/166 条 `f103` 与公式结果以十进制元精确相等，反例 0，最大绝对残差 0 元。各输入币种均为 CNY；所有使用的当前报告、上年同期报告与上年 Q4 的披露时间均不晚于对应行情数据日。

样本按个股最新已披露报告期选取，不将全体股票固定套用 Q2 或 Q3。2026-10-23 的样本中，力合微 `688589` 已于当天披露 Q3 报告，其余可比股票仍使用 Q2；2026-11-02 起使用各股票在目标日前已披露的 Q3 数据。

## 裁决与边界

对精确来源身份 `(东财-push2(stock/get), f103)` 定案为“经营活动现金流量净额 TTM”，单位“元”，规范名保留 `ocf_ttm(f103)`。定义限定于报告期口径的滚动十二个月值；不是本年累计现金流、单季现金流或上年全年值。此为来源内语义定案，不建立跨源 `mappings`。

没有找到东方财富公开的 `f103` 字段码释义，因此本裁决不声称获得了 Push2 的正式字段字典；字段身份由原始接口路径确定，语义由官方财务项目标签、发行人报告及全量合格历史样本的精确公式结果共同确认。Push2 服务端更新时点、追溯重述策略和 Eastmoney 字段码文档仍未核实；这些不改变当前已确认的指标类别、报告期口径和单位。
