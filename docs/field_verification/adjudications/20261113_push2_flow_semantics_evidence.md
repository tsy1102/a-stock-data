# 东方财富 Push2 资金流 f135/f136/f142/f143 来源内实证

## 结论范围

按精确来源路径 `东财-push2(stock/get)`，本次证据支持以下来源内语义，单位均为元：

| 完整来源路径 | 规范名 | 定案释义 |
|---|---|---|
| `东财-push2(stock/get)::f135` | `fund_main_buy` | 东方财富个股资金流分类下，当日主力类别买入金额；采集值等于超大单买入 `f138` 与大单买入 `f141` 之和。 |
| `东财-push2(stock/get)::f136` | `fund_main_sell` | 东方财富个股资金流分类下，当日主力类别卖出金额；采集值等于超大单卖出 `f139` 与大单卖出 `f142` 之和。 |
| `东财-push2(stock/get)::f142` | `fund_large_sell` | 东方财富个股资金流分类下，当日大单卖出金额；由大单买入 `f141` 减去大单净流入 `f143` 反推，并由全部可比较留存值复算。 |
| `东财-push2(stock/get)::f143` | `fund_large_today` | 东方财富个股资金流历史表“大单净流入/净额”对应的当日金额；三个官方页面值与原始采集值在页面显示精度内吻合。 |

以上是东方财富自身资金流分类口径，不表示特定账户、机构身份或交易所公布的真实主体资金流。东方财富 FAQ 明确表示交易所没有公布实时及盘后个股资金流数据，各软件自行计算；FAQ 问 36 给出的主力净流入公式是超大单流入减流出再加大单流入减流出。参见[东方财富资金流 FAQ](https://emdesk.eastmoney.com/pc_activity/Pages/VIPTrade/pages/link/zjl.html)（2026-11-13 核验，问 33、34、36）。

没有找到东方财富公开的 `stock/get` f 编号逐字段官方字典。因此，`f135`、`f136`、`f142` 的买卖角色是由东方财富页面标签、官方主力净流入公式、已核实的同源锚字段及留存原始值共同构成的**来源内实证结论**，不是声称官网发布过这些 f 编号的直接字段定义。没有创建跨源映射。

## 留存值恒等式复算

仅当目标值和公式两端均为数值时才比较；`-`、空值或缺值均记为不可比较，绝不当成 0。194 行是完整的日期合格观察集；下表中的“可比较”与“不可比较”之和均为 194，所有可比较行均精确相等，没有反例。

| 关系 | 可比较且吻合 | 不可比较 | 反例 | 不可比较缘由 |
|---|---:|---:|---:|---|
| `f135 = f138 + f141` | 159 | 35 | 0 | 至少一个字段为 `-` 或空；主要是 `f138` 缺项。 |
| `f136 = f139 + f142` | 162 | 32 | 0 | 至少一个字段为 `-` 或空；主要是 `f139` 缺项。 |
| `f142 = f141 - f143` | 187 | 7 | 0 | `f141` 或 `f142` 本身缺项。 |
| `f143 = f141 - f142` | 187 | 7 | 0 | `f141` 或 `f142` 本身缺项。 |
| `f137 = f140 + f143` | 194 | 0 | 0 | 全部行可比较。 |
| `f137 = f135 - f136` | 187 | 7 | 0 | `f135` 或 `f136` 缺项。 |
| `f140 = f138 - f139` | 150 | 44 | 0 | `f138` 或 `f139` 缺项。 |

`f137`、`f138`、`f139`、`f140`、`f141` 的既有注册语义与官方页面锚点用于解释公式角色；本次并未改写这些锚字段。`f143` 页面锚定后，`f142 = f141 - f143` 在 187/187 条可比较留存值中精确成立，支持 `f142` 为大单流出。进而 `f136 = f139 + f142` 在 162/162 条可比较值中成立；`f135 = f138 + f141` 在 159/159 条可比较值中成立。官方 FAQ 的主力净额公式以及本地 `f137 = f135 - f136`、`f137 = f140 + f143` 恒等式给出了独立的结构闭环。
