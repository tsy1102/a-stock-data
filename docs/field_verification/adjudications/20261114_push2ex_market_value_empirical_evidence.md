# 东财 Push2EX `total_value` / `circulating_value` 来源内实证

复核日期：2026-11-14

## 裁定范围

本次只确认精确来源路径 `东财-push2ex::total_value` 与 `东财-push2ex::circulating_value` 的来源内含义。前者定为总市值（元）；后者定为 A 股流通市值（元），即非限售流通 A 股股本乘该池记录价格，不是自由流通市值。裁定只覆盖 Push2EX `getTopicZTPool` 池记录的这两个输出字段，不外推到其他接口或同名字段，不建立跨源 `mappings`，不决定刷新时点或服务端精确股本更新规则。

## 上游定义与采集路径

- 东方财富 F10 指标页定义：总股本为最新已发行普通股数，总市值 = 最新股价 × 总股本；流通股本为扣除限售流通股后的 A 股股本，流通股市值 = A 股实时股价 × 流通 A 股。来源：[东方财富 F10 指标说明](https://aif10.eastmoney.com/PC_HSF10/OperationsRequired/Index)（2026-11-14 在线核对）。
- 项目 [`_pools.py`](../../../stock_common/sc_datasource/_pools.py) 的 `_parse_limit_pool` 将原始响应 `item["tshare"]` 原样数值化为 `total_value`，将 `item["ltsz"]` 原样数值化为 `circulating_value`；没有再对两个市值字段做比例换算。`collect_push2ex` 调用三个池接口，`get_limit_up_pool` 的请求为 `https://push2ex.eastmoney.com/getTopicZTPool`，参数 `date` 在未显式传入时由 `datetime.now().strftime("%Y%m%d")` 生成。
- 官方 F10 页面解释了业务指标公式，但没有给出 `getTopicZTPool` 的 `tshare` / `ltsz` 短键字典。因此本次走单源实证定案，不声称存在未找到的官方 API 字段字典。

## 全量历史样本的辅助检查与边界

- 仅使用 2026-10-15 起留存样本。按当前适配器的默认日期参数、同日收盘后运行元数据以及 KPL 同日 `as_of_date`，审查了 13 个数据日、1,190 条按股票代码去重的 Push2EX 股票-数据日池记录；其中与 KPL 股票记录可配对 781 条。Push2EX `price / 1,000` 与 KPL 已验证 `col_21` 在 781/781 条中精确相等，未缩放原值 0/781 条相等。该结果验证价格换算及收盘日配对，不单独用来定义市值字段。13 日为：20261015、20261019、20261020、20261026、20261028、20261029、20261102、20261103、20261104、20261105、20261109、20261110、20261112；其中仅 20261109、20261110、20261112 有来源级采集开始时间，其余十日使用旧版 `run_datetime` 回退，故不把它们当作正式官方股本样本。
- 已验证 KPL `raw_columns.col_13` 是“实际流通市值”。在同样 781 条配对中，Push2EX `circulating_value` 只有 39 条落在 KPL `col_13` 的 1% 内、44 条在 5% 内；`total_value` 没有一条落在 1% 内。该差异说明不可将本次 `circulating_value` 与 KPL 的“实际流通市值”直接画等号；不同概念并不构成对东财普通流通市值释义的反例。未创建两者映射。
- 对同日 Ulist239 `f20/f21` 的留存交集只有 1 条，不能替代官方发行人股本样本，也不足以主张跨接口精确映射；未用于定案或创建映射。
- 601123 马矿股份的 2026-11-03、2026-11-04 两条历史候选拥有官方股本文件，且计算结果的流通市值可对上；但对应归档缺少 Push2EX 来源级 `source_capture_started_at`，只能从整次任务 `run_datetime` 回退，故两行保留在 CSV 中但标记为“辅助、未计入正式样本”。其 `total_value` 分别相当于比官方 1,234,611,111 股少 7 股，不归因于舍入。本次正式样本没有因此隐去或重计。

## 裁定结论与限制

官方公式、两个来源日期合格的不同股票样本及精确解析路径，共同支持：`total_value` 是总市值（元）；`circulating_value` 是 A 股非限售流通股市值（元），不是自由流通市值。两项均按来源内实证 E3 入库。可比正式样本均无语义反例；本次不要求多日/跨源映射，亦不把微小差值称为舍入。

本结论不确认实时刷新时刻、股本变更推送时延、舍入精度或境外/其他类别证券的计算。旧归档缺少来源级开始时间的行不用于正式定案。本批只更新主字典语义元数据和生成视图，不修改采集、价格换算、缓存、来源路由或数据日期行为。
