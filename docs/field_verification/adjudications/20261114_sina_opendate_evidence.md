# 新浪个股资金流 `opendate` 日期字段实证

审阅日：2026-11-14。裁决对象仅为精确来源路径 `新浪(扩展API)::opendate`。

## 结论

`opendate` 是新浪个股资金流记录所对应的日期。本项目当前采集的最新资金流行中，它等于该来源实际数据日；可写为规范名 `opendate`、含义“新浪个股资金流记录所对应的交易日期”、单位“日期”。它表示记录日期，不是采集时间或盘中更新时间。没有证据据此建立与其他来源日期字段的等价映射，也没有证据确定精确盘中刷新时刻。

## 项目路径与官方资料

- `stock_common/sc_datasource/_eastmoney.py` 的 `get_sina_stock_fund_flow_raw()` 请求新浪官方主机 `vip.stock.finance.sina.com.cn` 上的 `MoneyFlow.ssl_qsfx_zjlrqs`，参数为 `num=1`、`sort=opendate`、`asc=0`，并返回 JSON 行，不改写字段。
- `scripts/capture_http_collectors.py` 的 `collect_sina_extended()` 将完整响应行保存至 `stocks.<code>.money_flow`，按最大 `opendate` 选择最新行，并将原始 `opendate` 值复制至 `stocks.<code>.opendate`。注册表完整路径对应这个标量副本；底层行值可用于逐条复核。
- 新浪[资金流向官方帮助页](https://finance.sina.com.cn/temp/guest4377.shtml)说明资金流向按交易所成交数据统计，讨论个股的每日资金流；其实时数据通常延迟 5–10 分钟，页面每 5 分钟更新。该页没有公开 `MoneyFlow.ssl_qsfx_zjlrqs` 的 JSON schema，也没有单独定义 `opendate` 键，因此本结论采用来源内实证流程，不称为逐字段官方契约。

## 注册表冲突处理与边界

原状态为 `status_conflict`：该来源参考状态是 `verified`，但注册表聚合状态为 `unverified`；精确来源字段没有 `attribute_conflicts`。本次数据路径和全量可比样本支持来源内释义，故解除该状态元数据冲突并把含义、单位补完整。该处理不改变其他来源的同名路径，也不新增 `mappings`。

日期值证明记录的日归属，不证明新浪资金流统计的精确盘中更新时间。新浪帮助页明确存在延迟和刷新间隔，因而不得把 `opendate` 当成报价的精确时点或采集时间。
