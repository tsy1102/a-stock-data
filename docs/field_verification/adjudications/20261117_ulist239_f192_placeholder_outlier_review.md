# 2026-11-17 Ulist239 `f192` 候选与来源语义复核

## 结论

`东财-ulist239(np/get)::f192` 继续保持 `unverified`，本轮不改主字典、不建立跨源映射。当前最强语义假设是：`f192` 表示 A/H 对应证券的市场号；601288 农业银行样本中，`f191=01288`、`f192=116`、`f193=农业银行`，与其 H 股身份相符。该假设有第三方 Eastmoney 接口字段表支持，并由东方财富 A 股/H 股页面核对了证券配对，但尚缺底层接口的官方字段契约或第二只不同 A/H 股票的项目原始样本。

这与已撤回的宽泛解释“A+H 双上市标识”不同：`116` 更像对应市场编号，`-1` 是没有对应值时的占位候选，而不是布尔标志本身。当前证据不足以验证所有市场编号或占位规则，因此不写入注册表。

## 25 条拟合候选为何不能定案

碰撞报告为 `f192` 生成 25 条方法候选，右端分布在 TDX、Tencent、FTShare、ELTDX 与 ZHB 字段。样本量是 20 或 40 行，覆盖 1 或 2 个 Ulist 数据日；所有候选都共享同一组股票，且只有 601288 的 `f192` 是非负值。高相关或高 `R²` 因而不能区分市场号编码与“唯一非占位股票恰好是大市值/大股本发行人”等替代解释。

最醒目的例子：

- `f192 ↔ TDX finance_info.hgu`：40 行、Pearson/Spearman 均为 1，拟合 `hgu ≈ 26272.498 × f192 + 26272.498`。38 行是 `f192=-1` 对 `hgu=0`，另 2 行是同一只 601288 重复两日的 `116` 对 `3,073,882.25`；精确数值并不相等，且唯一正样本股票重复了相同财务记录。
- `f192 ↔ Tencent[76]`：40 行，拟合 `R²=0.99962`。唯一 `f192=116` 的 601288 同时是本样本里该 Tencent 字段的极端值；回归被单个发行人支配，不能推出两字段有共同含义。
- 其余候选同样没有新增独立的 `f192` 有效值或不同 A/H 股票。25 项均已在候选审阅台账标记为 `insufficient_evidence`；该处置只拒绝这些数值关系的证明力，不表示 `f192` 语义已证伪。
