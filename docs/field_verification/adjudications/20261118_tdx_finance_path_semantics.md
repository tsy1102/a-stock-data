## 字段释义旁证和解释边界

通达信官方公式帮助分别把 `FINANCE(20)`、`FINANCE(21)`、`FINANCE(23)` 列为营业收入、营业成本、营业利润。本帮助没有公开给出 Easy-TDX 0x0010 的这些完整 FinanceInfo 键到公式编号的官方映射，因此该页面只作为官方术语旁证；具体路径的定案依据是项目适配器路径追踪与三份发行人合并利润表逐值核对。

项目固定的 Easy-TDX 1.20.8 `FinanceInfo` 来源契约曾将 `zhuying_shouru` 记录为“主营收入、元”。当日直接输出与 2026Q3 正式报告的三组比较证实原输出实际按角计；本裁决明确更正当前含义/单位，旧来源契约作为审计历史保留。`zhuying_lirun` 上游拼音/模型标签不能替代数值证据；此处确认的是实测“营业成本”。

`zhuying_lirun` 与 `zhuyinglirun` 是同一 Easy-TDX FinanceInfo 行在项目适配器中的原字段/代码生成别名；两者保留独立完整路径记录并使用同一 canonical `zhuyinglirun`。`zhuying_shouru` 与 `zhuyingshouru` 同理，canonical 采用既有已核实值 `zhuyingshouru`。本次未添加 mappings；`zhuyinglyrun` 和 `zhuyingshouru` 的既有定义也不变，只追加同日双适配器观察。
