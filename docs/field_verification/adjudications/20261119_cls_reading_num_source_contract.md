# 财联社 `reading_num` 来源契约核验（2026-11-19）

目标身份：`财联社(cls)::reading_num`。

## 定义与边界

确认该字段为财联社电报记录的阅读计数，即官方滚动电报接口响应中的 `reading_num` 值。采集器保留接口当次返回值；它是动态计数，不代表唯一读者数，也不承诺与之后打开详情页所见数值逐值相同。计数去重口径、刷新延迟，以及列表接口与详情页显示数是否同一统计口径仍未确认，单位留空。

本决定只确认 `财联社(cls)::reading_num`。不把 `reports::reading_num` 的相同短代码视为同一字段，不创建跨源映射，也不将该字段用于日频行情碰撞。

## 路径映射与采集样本

项目的 [`cls_telegraph()`](../../../stock_common/sc_datasource/_eastmoney.py) 调用财联社官方 `https://www.cls.cn/v1/roll/get_roll_list`，从响应 `data.roll_data[]` 逐条读取 `item.get("reading_num", 0)`，原样写入输出 `reading_num`，没有换算或合并到其他统计字段。该接口请求参数使用 `appName=CailianpressWeb`、`os=web`、`sv=7.7.5`。

2026-11-18 归档中，恒瑞医药电报标题为“恒瑞医药：获得药物临床试验批准通知书”，条目时间为 `2026-11-18 16:59:50`，`reading_num=3998`。该来源采集开始时间是 `2026-11-18 17:00:17`。财联社官方[同一标题文章页](https://api3.cls.cn/share/article/2537973?app=&os=android&sv=876)也显示相同发布时间，并以“阅读”标注页面计数。该页面曾在 Android 请求上下文观察到 `1,367,035`；2026-11-19 08:49（中国标准时间）搜索到的 iOS 请求上下文页面则显示 `183,932 阅读`。两者都不是与约 17:00 归档值同一时点、同一客户端上下文的比较，且页面版本间数值不一致，不能据此声称数值相等或推断变化算法。它们仍与字段作为“阅读数”的角色相符，但不能证明列表接口与详情页统计口径相同。

另一条中国巨石电报的归档 `reading_num=161338`，官方[文章页](https://api3.cls.cn/share/article/2537881?app=&os=android&sv=837)搜索快照曾显示 `33,688 阅读`。页面版本和读取时点没有与 2026-11-18 的接口请求对齐，因此该差异不能用来确认或否定精确数值口径，也不被解释为已证实的计数更新机制；它说明目前不能把列表接口值等同为任何后续页面显示值。相同恒瑞文章的当前官方 [iOS 页面搜索结果](https://api3.cls.cn/share/article/2537973?app=&os=ios&sv=839)可见发布时间和 `183932 阅读`，而较早 Android 页面观察值为 `1,367,035`。
