# Eastmoney IPO `ISSUE_NUM` 与 `ISSUE_PRICE` 定案

复核日期：2026-11-20

## 定案

- `东财-event_dc(IPO发行记录)::ipo_calendar[].ISSUE_NUM`：该 IPO 发行记录的发行总股数，东方财富官方页面以**万股**显示；它不是网上发行数量，也不是发行后的总股本。样本与发行人资料的精确度并不完全一致，万科一例为 2,800 万股对发行人披露的 2,808.6 万股，差 8.6 万股（约 0.31%）。因此定案字段角色与单位，但不把每个历史记录值宣称为精确到股。
- `东财-event_dc(IPO发行记录)::ipo_calendar[].ISSUE_PRICE`：该 IPO 发行记录的**每股发行价格**，单位元/股；不是上市首日价格或当前价格。

两项裁决仅限定于上述 Eastmoney 完整路径，不新增跨源映射。`ISSUE_NUM` 的数值精度差异保留为源数据质量观察，不据此否定官方页面明确给出的字段角色。

## 来源契约与路径

- 项目 [`_events.py`](../../../stock_common/sc_datasource/_events.py) 将 `ipo_calendar` 请求配置为 `RPTA_APP_IPOAPPLY`，将响应行原样放入 `raw_event_dc.ipo_calendar[]`。
- 东方财富[新股申购数据页](https://datapc.eastmoney.com/da/Purchase/Index)的官方模板将 `item.ISSUE_NUM` 绑定到“发行总数（万股）”列，并将 `item.ISSUE_PRICE` 绑定到“发行价格”列。数据页说明发行总数、发行价等部分历史估算数据可能受募集资金、发行数量及费用数据影响，实际数据更新后会同步更新。
- 来源采集调用链：`_events.py::_EM_REPORTS['ipo_calendar'] -> RPTA_APP_IPOAPPLY response.data[*].{ISSUE_NUM, ISSUE_PRICE} -> ipo_calendar() -> raw_event_dc.ipo_calendar[].{ISSUE_NUM, ISSUE_PRICE}`。项目没有对这两个字段做换算或重命名。
