# 开盘红 `industry_limit_up_count` 来源内语义实证

复核日期：2026-11-20。精确字段身份：`开盘红::industry_limit_up_count`。本裁决只确认开盘红自身字段的业务角色，不建立与开盘啦、东财或其他来源的字段映射。

## 裁决

将该字段的来源内含义确认并登记为：**开盘红按其自身 `industry_id` 分类关联的当日涨停股票家数**，单位“家”。开盘红没有公开字段手册说明 `row[27]` 的统计集合或分类体系；因此确切行业层级、纳入股票范围和接口过滤口径仍未知。该数不能解释为“本次 KPH 历史涨停响应中该行业的行数”，也不能外推成全市场完整行业总数。

开盘红（KPH）与开盘啦（KPL）各有独立官网、产品身份和接口主机。两站页脚虽列同一运营公司，仍分别登记为来源族 `kph` 与 `kpl`。本裁决的语义证据只使用开盘红官方产品说明、KPH 精确响应映射和 KPH 本地样本；KPL 数值不用于定义 KPH 字段。

## 字段路径和官方产品语义

本项目 [`_kph.py`](../../../stock_common/sc_datasource/_kph.py) 将 KPH 历史接口 `HisDaBanList` 响应的 `row[26]` 映射为 `industry_id`、`row[27]` 映射为 `industry_limit_up_count`。固定版本的独立 Levistock 客户端使用相同开盘红历史接口参数，把 `row[26]` 解析为 `industry_id`、`row[27]` 解析为 `industry_zt`，并明确注释为“同行业涨停数”；该客户端映射是独立佐证，不是开盘红正式 API 字段契约。[固定版本源码](https://github.com/fleetinglife/levistock/blob/808d8187a6dd2a781dc51efeb1581f35d68e66c7/levistock/stock/stock_daban_his_kph.py)。

开盘红官网的[盘后复盘教程](https://www.kaipanhong.com/article/42661) 明确以“同一板块内涨停家数”解释板块集中度，并举例说明一个板块当天有 5 只涨停股。它支持本字段的业务语义类别和计量单位，但没有公布 API 原始列到官网展示项的精确对应。官网[首页](https://www.kaipanhong.com/)与[开盘啦官网](https://www.kaipanla.com/)分别展示“开盘红”和“开盘啦”产品；这证明产品身份区分，不证明字段等价。

## KPH 来源内样本

使用 2026-11-16、17、18 三个不同 KPH 来源交易日的完整分页快照。每个样本 `pagination.complete=true`；每个来源日仅计一次。2026-11-19 捕获的另一个 2026-11-18 快照与 11 月 18 日来源日相同，按日期规则排除，不当作独立样本。

- 103 条 KPH 涨停股票记录分属 43 个“来源交易日 × `industry_id`”组。
- 43/43 组内的 `industry_limit_up_count` 值一致；同一行业代码组中的股票重复携带同一个计数。
- 其中 38/43 组的字段值也恰等于本次 KPH 返回列表的该组行数，共覆盖 71/103 条股票记录。
- 另有 5 组计数大于返回行数：2026-11-16 `801031` 为 5 对 4 行；2026-11-17 `801346` 为 2 对 1 行、`801807` 为 5 对 4 行；2026-11-18 `801001` 为 3 对 1 行、`801807` 为 23 对 22 行。

这些样本支持字段随 KPH 自身行业分类表示行业涨停家数；五个例外同时否定了“该值只是当前 KPH 响应分组行数”的替代解释。例外无法确定 KPH 更广计数集合的成员资格，因此本次把集合范围明确留为未知。逐组复核结果见[43 组来源内样本](../research/20261120_kph_industry_limit_up_count_group_samples.csv)。

## 与 KPL 字段的边界

开盘红和开盘啦是不同数据源，不以同一运营主体推断同源。此前按来源日期逐股对齐的 KPH/KPL `industry_limit_up_count` / `raw_columns.col_20` 共有 103 组、83 组逐值相同；20 个反例阻止建立直接等价映射。该对照仅用于拒绝跨源映射，不参与本次 KPH 来源内语义定案。KPL `col_20` 已有自己的来源内定义，不能反向充当 KPH 官方字段解释。

## 证据边界

- 已确认：精确 KPH 路径的来源内角色为按开盘红 `industry_id` 分类关联的当日涨停股数，单位“家”。
- 仍未知：`industry_id` 的正式分类体系、层级、计数纳入范围以及统计集合是否覆盖 KPH 当前历史接口未返回的记录。
- 未确认：该字段与 KPL `col_20` 或任何其他来源逐值同义；不新增 `mappings`，不改变任何来源的采集或碰撞路由。
