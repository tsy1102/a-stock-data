# 财联社 `level` 电报展示等级来源契约核验

复核日期：2026-11-21。

## 裁决

将 `财联社(cls)::level` 定案为财联社电报记录的**网页展示等级代码**，规范名 `cls_telegraph_display_level_code`，无计量单位。当前官方电报页对 `A`、`B` 使用红色文本，对 `A` 额外加粗；其他值走默认文本样式。

结论范围仅限字段在当前官方 Web 前端中的展示作用。官方页面脚本没有给出完整代码全集、每个代码的业务名称、重要性排序或分类判定规则；本记录不把 `A/B/C` 扩写为“重大/较重要/普通”，也不将这个字段与其他来源的通用 `level` 建立映射。

## 精确运行路径与官方前端

- 项目 [`_eastmoney.py`](../../../stock_common/sc_datasource/_eastmoney.py) 的 `cls_telegraph()` 请求 `https://www.cls.cn/v1/roll/get_roll_list`，读取响应 `data.roll_data[*].level`，原样写入 `raw_cls.json` 的 `telegraph[].level`；项目不重编码或换算该值。
- 财联社[官方电报页面](https://www.cls.cn/telegraph)加载其[官方前端脚本](https://wwwjs.cls.cn/_next/static/chunks/pages/telegraph-4347dce294585c13.js)。该脚本同样调用 `/v1/roll/get_roll_list`，从 `roll_data` 读取记录，并在记录渲染组件中直接检查 `item.level`：`A` 或 `B` 使用红色类 `c-de0422`，`A` 再使用粗体；其他值使用默认颜色和常规字重。页面导航也存在“加红”筛选项。
- 核查时下载的官方脚本 SHA-256：`745941d158ae0fd488d6fb8bca1a6b9b7daefd8c4fb721a41dcfe28d3f3409b12`。该摘要固定本次观察到的前端版本；它不代表财联社发布了独立 API 字段字典。

## 留存样本复核

按 `scripts/capture_retention.py` 的保留起点 2026-10-15，读取现有 `raw_cls.json` 和对应采集元数据，没有发起采集请求：

- 22 个归档原始文件的采集状态均为 `ok`；其中 2026-10-15 文件记录数为 0，其余 21 个日期合计 1,050 条电报记录。
- 1,050 条记录的 `level` 均为非空字符串，均有可解析的 `time`；观察到 `A=2`、`B=122`、`C=926`，没有其他取值、缺失值或非字符串值。
- `time` 是记录时间，采集目录是采集/目标日期；二者单独保存。本次字段语义是前端展示行为，不用目录名替代记录时间，也不从记录时间推断重要性或分类生效日。
- 逐目录记录数、取值分布、事件时间范围和原始文件 SHA-256 见[保留期审计 CSV](../research/20261121_cls_level_retained_audit.csv)，规范 LF SHA-256：`1d0097be97c1de30dfb466b6661ac698e8b21b2e50626785d0df2b162d3b40e0`。

## 来源身份及字段边界

`reports::level` 是另一个完整来源路径，仍按自身证据保持未验证。旧的通用规范名 `level` 会让两个没有已证实等价关系的来源落入同一聚合，本次将财联社路径改用唯一规范名。此举不建立跨源映射，不改变采集行为，也不把 `reports::level` 一并定案。

财联社原始记录没有单独提供此展示字段的来源有效日期；A/B/C 的业务全称和分类规则仍待官方资料说明。若官方后续改变前端规则，应以新版本证据复核展示效果，不自动外推历史版本。
