# 东方财富 clist `f259` 市场路由编号来源内实证定案

审阅日期：2026-11-23。目标仅为精确路径 `东财-clist::f259`；不定义 `f257/f258` 关联证券的选择规则，不建立跨来源映射。

## 定案

`f259` 是同一板块统计行中 `f258` 证券代码对应的东方财富行情路由市场编号。保留样本中观察到 `0` 与 `1`：`0` 对应样本中的深市与北交所路由代码，`1` 对应样本中的沪市路由代码。规范名为 `clist_associated_security_market_id`，单位为“东财行情路由市场编号”。

此为完整留存样本上的来源内实证释义，不是东方财富已公开的 `f259` 字段表定义。只确认本次观测到的值与路径；不推广到未观察的市场编号、其他 clist 业务类型或其他接口。

## 路径与一方页面证据

项目 `scripts/capture_http_collectors.py::collect_clist` 请求东方财富 `/api/qt/clist/get`，在 `fields` 参数中显式包含 `f257,f258,f259`，并将响应行透传到 `raw_clist.records[]`；本批原始路径为 `raw_clist.records[].f259`。采集字段列表及原始响应解析可在[项目采集器](../../../scripts/capture_http_collectors.py)复核。

东方财富[板块资金流页面随页脚本](https://data.eastmoney.com/newstatic/js/bkzj/list.js)于 2026-11-23 返回 HTTP 200。实取脚本 81,715 字节，SHA-256 `9DE0D1B6EBFDBF7E02894F78EF1383DF6852E2156714A07508A91B59379F1808`。脚本把 `f257` 绑定到 `zdname`、`f258` 绑定到 `zdcode`，并将两项用于 3 日/5 日统计行；`zdname` 的链接格式器读取同一行 `zdcode`。当前脚本中没有 `f259` 的绑定，因此不能把 `f259` 的释义冒充为东方财富明文标签。

同一来源已核验的 `f140/f141` 与 `f208/f209` 分别为领涨、领跌证券的代码/行情路由市场编号；既有决定见 [`20261122_exhaustive_source_paths.json`](20261122_exhaustive_source_paths.json)。这些字段只作为同接口、同记录中已知市场编号的参照，不因相邻编号而假定含义。
