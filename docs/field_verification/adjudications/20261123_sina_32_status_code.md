# 新浪行情 `[32]` 状态码来源内实证

复核日期：2026-11-23。未运行采集；仅读取保留边界内已有归档并查询公开公司公告。

## 裁决

将 `新浪(hq.sinajs)::[32]` 定义为**实时行情交易状态码**。本次能够确认的已观察代码为：

- `00`：常规交易状态。本次保留样本中 439/439 条均为正成交量记录，且独立腾讯行情字段 `[40]` 未显示停牌标记。
- `03`：停牌。本次唯一记录为 600825 新华传媒的 2026-10-15 行情；新浪 `[32]` 为 `03`、成交量和成交额均为零、逐笔字段为空。巨潮资讯 2026-10-13 停牌核查公告列明停牌起始日为 10-13；10-16 复牌公告追溯列明停牌终止日为 10-15、复牌日为 10-16。次日同一股票新浪 `[32]` 回到 `00`，并出现正成交量与成交额。

以上只确认样本中出现的 `00`、`03`；**不声称已穷尽或解释接口的其他状态码**。本结论确认字段角色及两个已观察值，不建立跨源 `mappings`。腾讯 `[40]` 的值仅作独立交叉佐证，不单独承担新浪字段定义。

## 路径、日期与样本

采集器 `scripts/capture_http_collectors.py::collect_sina` 请求 `https://hq.sinajs.cn/list={symbol}`，按逗号拆分响应并将顺序保存在 `raw_sina.json.stocks[股票代码].fields`；目标完整路径是该列表的索引 `[32]`。来源参考表 §12.2 已把位置 `[32]` 记为“状态码”，此前仅 `00=正常?` 未定。

读取 `MIN_CAPTURE_DATE=2026-10-15` 之后的全部新浪行情归档：22 个有样本交易日、每个交易日 20 只股票，共 440 条。每条记录的目录数据日、`meta.data_date`、新浪同记录 `[30]` 日期、腾讯同条 `[30]` 时间戳日期 440/440 一致；没有用采集自然日替代来源数据日。完整逐条数据、原始文件路径和文件 SHA-256 见 [样本审计 CSV](../research/20261123_sina_32_status_code_samples.csv)，CSV SHA-256：`f2d29f7fb9e72ab60c51e3937de3492b7e675f183859973f8131a54edaf0bc58`。

## 样本边界

- 样本限于 `MIN_CAPTURE_DATE` 之后现存的 22 个归档日期；不读取更早归档，也不采集新数据。
- 20 只样本证券在这些新浪归档中均可见；`00` 的 439 条观察全部有正成交量。37 条 `00` 记录的逐笔字段为空，但成交量仍为正，因此不以逐笔字符串是否存在作为状态判断条件。
- `03` 仅有一个停牌实例，不过该实例由发行人正式停牌/复牌公告、停牌前后同一股票的行情变化和另一独立行情提供方的标记同时区分；这支持来源内状态码解释，不外推其他状态值。
- 样本 CSV 带每条记录对应的新浪、腾讯原始文件路径与字节 SHA-256，供复核原始归档完整性。
