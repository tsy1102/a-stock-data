# 东方财富 Push2 `stock/get::f178` 日度主力净流入数组来源内实证

- 核验日期：2026-11-24
- 精确字段身份：`东财-push2(stock/get)::f178`
- 决策范围：只确认 Push2 `stock/get` 返回对象中的这一条完整路径；不建立跨来源映射，也不把结论转给 Ulist239 的 `f178`。

## 结论

`f178` 是包含 5 条带日期日度记录的主力资金净流入数组。每项包含 `date`（`YYYY-MM-DD`）和 `mainNetAmt`（元）；日期按新到旧排列。保留样本中，数组最新日期均早于同记录 `f86` 响应日期：180 个数组相差 1 个自然日，54 个数组相差 3 个自然日，后者对应周一响应与前一周五日期。因此不能把响应日期或采集目录日期替代成数组元素的数据日期。

逐项对照同一证券、同一 `array_date` 的 Push2 `f137`，可比较的 576 条数组元素全部精确相等；这些比较对应 214 个去重证券—日期对，未发现反例。`f137` 已独立核实为当日主力资金净流入、单位元。官网的“5日排行”和“5日主力净流入”页面为产品层级佐证；官网没有公开 `stock/get::f178` 的键级字段契约，故本结论按来源内样本实证登记，不称为官方接口字段文档释义，也不推断订单类别阈值或资金参与者身份。

## 样本与日期资格

- 仅审查 `MIN_CAPTURE_DATE=2026-10-15` 之后的 Push2 raw 归档。20 个归档目录的 Push2 状态为 `ok` 9 个、`partial` 4 个、`failed` 7 个；只使用前两类共 13 个 raw/meta 文件。失败目录的 raw 内容未作为字段样本读取；包括带保留快照标记的 2026-11-16、2026-11-19 失败目录也排除。
- 对每条记录，均将同记录已验证日期锚 `f86`（Unix 秒）换算为北京时间，并要求结果与采集目录日期相同；234 个有效 `f178` 响应数组全部通过，另无日期锚不一致记录。
- 234 个数组各有 5 项，日期均唯一且降序，共 1,170 项。数组中 24 项日期早于 2026-10-15 保留边界，未作为样本；其余 1,146 项进入逐项审计。
- 1,146 项中，576 项找到保留期内同证券、同日期的 `f137` 记录并精确相等；570 项没有可用的同日期 `f137` 原始记录，列为未比较，不计作命中或反例。失败目录、边界前数据及无同日比较值均未计入命中数。

## 来源与实现核对

项目适配器在 [`stock_common/sc_datasource/_quotes.py`](../../../stock_common/sc_datasource/_quotes.py) 从 Push2 响应 `data.f178` 解析 JSON 数组，并读取每项 `mainNetAmt`。这是项目运行路径核对，不是上游字段说明。

东方财富官方[沪深两市主力净流入排名](https://data.eastmoney.com/zjlx/list.html)区分今日、5日和10日排行榜；官方[资金流监测](https://data.eastmoney.com/bkzj/jlr.html)列出“5日主力净流入前10名”。这些页面支持“5日主力净流入”的产品概念，但未展示该接口键 `f178` 的结构定义。`f137` 的当日主力净流入页面观察证据详见 [`public_web/20261109_push2_large_flow.md`](public_web/20261109_push2_large_flow.md)。

## 适用边界

- `date` 是数组中各日金额自身的数据日期；响应 `f86` 仅作为记录观测日期锚，不覆盖数组元素日期。
- 576 条比较中有跨重复滚动数组产生的重复证券—日期观测，因此比较条数不是 576 个独立日期样本；去重后为 214 个证券—日期对。
- 570 项缺少同日 `f137` 记录，不能据此扩大精确一致结论；本批也没有独立于东财的资金流来源验证。
- 此结论不表示 Ulist239 `np/get::f178` 与 Push2 同义，不添加 `mappings`，不改变采集路由或代码行为。
