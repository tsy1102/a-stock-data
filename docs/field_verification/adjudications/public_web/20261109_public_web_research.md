# TDX `finance_batch` 财务字段公开资料核验

> 核验时间：2026-11-09（Asia/Shanghai）
> 范围：`TDX-eltdx(适配层)` 的 5 个原始财务字段。本文是公开资料研究记录，不是注册表裁决；没有创建跨源 `mappings`。

## 结论

保留样本与 2026 年半年报、三季报高度吻合，支持以下语义推断：

- `eps_raw` 是基本每股收益，样本取年初至报告期末的累计值。三季报单季度值与累计值不同，原始值匹配累计值。
- `zong_gu_ben_raw_float` 是总股本，单位为万股。泸州老窖 2026-06-30 的股本与原始值仅差 56.75 股，落在该量级 float32 值的半个 ULP（78.125 股）内。
- `zong_zi_chan_raw_float` 是总资产；`jing_li_run_raw_float` 与归属于母公司股东的净利润吻合。按留存样本对照，二者的原始单位均应为千元。农行报告只披露到百万元，故较大金额的残差来自报告显示精度及采集 float32 精度，比例很小。
- `liu_tong_gu_ben_raw_float` 很可能是流通股本，单位为万股；本次没有找到按相同股票和日期公开的流通股数量来完成数值复核。

这些结果尚不足以把五条 `(source, 完整 code path)` 登记为已验证：通达信公开的 `get_stock_info_batch` 字典定义了 `ActiveCapital`、`J_zgb`、`J_zzc`、`J_jly`、`J_mgsy2`，但没有说明这些键与项目采集的 0x0010 `finance_batch` / `FinanceInfo` 原始属性之间的精确映射。项目适配代码说明本地路径如何形成，上市公司报告说明数值对应的业务指标；两者没有补上官方 0x0010 字段表这一环。因此本次不运行注册表应用器，五条原始路径维持原状态。

农行总资产误差分别约为报告披露金额的 0.0000013% 和 0.0000019%，因为报告金额只显示到百万元。泸州老窖 2026 年三季报同时列出本季度基本每股收益 0.90 和年初至报告期末累计基本每股收益 3.85；采集值 3.85 因而支持累计口径，而非单季度口径。上述差异均按报告精度和原始 float32 精度解释，未因尾数微差否定字段。

## 上游文档及解释边界

通达信量化平台官方 [`get_stock_info_batch` 文档](https://help.tdx.com.cn/quant/docs/markdown/mindoc-1ctuhthaq5qmg/mindoc-1hlnuonsp0amo.html)在返回字段表中说明：`ActiveCapital` 为流通股本（万股）、`J_zgb` 为总股本（万股）、`J_zzc` 为总资产（万元）、`J_jly` 为净利润（万元）、`J_mgsy2` 为财报提供的季报每股收益。该页面是项目所需的同一数据提供方定义，但接口为 `get_stock_info_batch`，不是项目的 `finance_batch` 0x0010。

通达信官方 [`get_financial_data` 文档](https://help.tdx.com.cn/quant/docs/markdown/TdxQuant.md/mindoc-1h10m001ic888.html)另定义 FN1 为基本每股收益，并声明未标单位的资金项以元、股本项以股计。它是另一财务接口，不能据此推定 0x0010 原始字段的单位或列映射；本备忘录只将其作为区分接口的边界说明。

公开报告对照中：

- 贵州茅台 2026 年[半年度报告](https://static.cninfo.com.cn/finalpage/2026-08-15/1225475868.PDF)与[第三季度报告](https://static.cninfo.com.cn/finalpage/2026-10-31/1225649896.PDF)提供 EPS、总资产和归母净利润。
- 农业银行 2026 年[半年度报告摘要](https://www.abchina.com.cn/cn/aboutABC/investor_relations/announcements/a-announcement/202608/P020260828677107564380.pdf)与[第三季度报告](https://www.abchina.com.cn/cn/AboutABC/investor_relations/announcements/a-announcement/202610/P020261030669574034294.pdf)提供 EPS、总资产和归母净利润；金额按人民币百万元披露。
- 泸州老窖 2026 年[半年度报告](https://disc.static.szse.cn/download/disc/disk03/finalpage/2026-08-26/dddd84cb-a0dd-4ceb-89c3-840c16ceafda.PDF)与[第三季度报告](https://disc.static.szse.cn/download/disc/disk03/finalpage/2026-10-30/477d3881-379b-47af-ac0c-1f0197daf522.PDF)提供 EPS、总资产、归母净利润及总股本。

## 尚未定案项

1. 没有找到公开的通达信 0x0010 正式字段表，能把 `FinanceInfo.eps`、`liutongguben`、`zhongguben`、`zongzichan`、`jinglirun` 逐一对应到官方接口字段。当前意义来自项目映射、同一提供方公开字段定义和多公司多报告期值级复核的合并推断。
2. `liu_tong_gu_ben_raw_float` 尚未用同一日期的官方流通股数量复核；当前不能细分为流通 A 股、全部上市流通股或其他股本口径。
3. `jing_li_run_raw_float` 在三家公司两期数据中吻合的是“归属于母公司股东的净利润”；通达信公开字段表只写“净利润”。在 0x0010 字段定义未补齐前，不把这种稳定吻合写成该原始路径的正式字段契约。
4. `updated_date` 对 000568 半年报样本为 2026-09-24，而报告发布日期为 2026-08-26；它不是可直接替代报告期或披露日期的证据字段。

因此本次不修改 `field_registry.json`，不新增 source contract、跨源映射或已验证字段。后续若获得通达信正式 0x0010 字段定义，或获得同一 0x0010 路径的官方逐股响应及可复核日期，再按精确来源路径完成注册表裁决。
