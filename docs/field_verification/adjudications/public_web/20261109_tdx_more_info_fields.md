# TDX 扩展字段与财务字段公开资料核验

核验日期：2026-11-09。

## 通达信官方接口

[通达信量化平台官方接口文档](https://help.tdx.com.cn/quant/docs/markdown/mindoc-1hjbidnohpjn4/mindoc-1hlir5r0t9hgc.html)分别列出：

- `get_market_snapshot_batch`：实时行情快照字段，文档字段表位于页面“批量获取实时行情快照”章节。
- `get_stock_info_batch`：证券基本信息与财务字段。
- `get_more_info_batch`：扩展行情、资金、估值、财务和日期字段；其返回字段表从 `HqDate` 开始，并包含本次核验的 77 个未知字段及此前已登记的 11 个日期字段。表中声明这些字段的数据类型为 `str`。

先前的 `20261109_tdx_snapshot_dates` 记录将 11 个日期字段误归入 `get_market_snapshot_batch`。重新按官方页面的章节与字段表核对后，现更正为 `get_more_info_batch`；日期语义不变，官方仍未说明日期字符串格式。
