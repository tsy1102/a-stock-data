## 官方接口定义边界

- 通达信量化平台的 [`get_financial_data` 文档](https://help.tdx.com.cn/quant/docs/markdown/TdxQuant.md/mindoc-1h10m001ic888.html)将 `tag_time` 定义为报告期，将 `FN1` 定义为基本每股收益，并分别列出 `announce_time` 与 `tag_time`。这支持“报告期”和“每股收益”两个字段类别；它没有公开定义本项目 `tipinfo.dat` 的列号，也没有证明 ZHB `[3]` 与 `FN1` 是同一接口字段。
- 通达信 [`getmarketsnapshot_batch` 文档](https://help.tdx.com.cn/quant/docs/markdown/mindoc-1hjbidnohpjn4/mindoc-1hlir5r0t9hgc.html)把 `ReportDate` 描述为“最近财报公告日期”。此定义不能解释 ZHB `[4]` 在实际报告公布后仍保留较晚日期的样本，因此本裁决不把 `[4]` 认作 `ReportDate`，也不将其解释为实际公告日。
- 项目解析器位置映射见 `core/zhb_client.py::_parse_tipinfo()`；该代码只能证明项目如何读取 ZHB 文件，不冒充通达信对原始列号的公开定义。

## `[4]` / `disclose_date`：预约日期与实际公告时间

ZHB 在 `20260930` 报告期对应的 `disclose_date` 分别为平安银行 `20261024`、宁德时代 `20261021`、贵州茅台 `20261031`。东方财富官方[平安银行个股日历](https://data.eastmoney.com/stockcalendar/000001.html)、[宁德时代个股日历](https://data.eastmoney.com/stockcalendar/300750.html)和[贵州茅台个股日历](https://data.eastmoney.com/stockcalendar/600519.html)的“预约披露日”分别给出相同日期。

巨潮资讯的[贵州茅台公告列表](https://www.cninfo.com.cn/new/disclosure/stock?plate=sse&stockCode=600519)显示 2026 年三季报于 `2026-10-30 16:00` 公告，早于预约日 `2026-10-31`；而 2026-11-06 的 ZHB 包仍保留 `20261031`。这是一条直接区分预约日和实际公告日的反例。平安银行三季报官方[报告原件](https://static.cninfo.com.cn/finalpage/2026-10-24/1225620609.PDF)的报告日期为 2026-10-24，与预约日相同，作为值匹配样本，不承担区分预约/实际日期的判别作用。宁德时代同样仅作值匹配样本。

`docs/field_verification/20261023/meta.json` 记录该样本于 `2026-10-24 15:16` 实际采集；由于可访问的官方记录未能确认平安银行当日的精确发布时间，此样本不用于证明“采集在实际公告之后”。预约日结论主要由贵州茅台的官方公告时间与 2026-11-06 ZHB 保留值区分。历史样本也显示部分预约日与实际发布日期相同；不能仅凭日期相同将其解释为实际公告日。

## 结论边界

- 报告期与累计 EPS 的含义由本地解析位置、15 个保留包的逐行对应和发行人定期报告共同支持；官方通达信文档用于确认财务字段类别，不作为 ZHB 列号定义。
- 预约披露日由三个不同股票的东方财富官方个股日历对照，且由平安银行、贵州茅台的实际公告时间反证“实际公告日”解释。
- 本记录不创建跨源字典映射，不推断未见字段的命名规则，不依赖 2026-10-15 以前的样本。
