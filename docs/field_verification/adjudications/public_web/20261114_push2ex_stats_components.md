## 语义与边界

- `zt_continuous` 是“涨停统计”组合中的板数分量，对应 `zttj.ct`；它不是官方单列的当前连续连板数。例如 002623 页面显示 `5/8`、`4连板`，002172 显示 `6/12`、`首板`。
- `zt_days` 是同一组合中的天数分量，对应 `zttj.days`。页面没有公开天数按自然日还是交易日计算、统计窗口如何起算或累计规则。
- 2026-11-12 财富号用户复盘[将 002623 记作“8天5板”、002086 记作“17天9板”](https://caifuhao.eastmoney.com/news/20261112122528524281580)；该内容为用户发布，只作术语方向的辅助线索，不视为 Eastmoney 官方字段定义或第二份官方数据证据。
- 历史 ZHB 对撞出现统计口径反例；本记录不建立 `zt_continuous`/`zt_days` 到 ZHB `stat.zt_count`/`stat.zt_streak_cycle` 的跨源映射。
- 页面不显示两个分量的单位后缀；`display_unit` 保持空白。注册表单位依据接口路径与页面列语义分别记为“板”和“天”。
