# 开盘啦板块强度官方页面核验

核验日期：2026-11-24（北京时间）。本次只核对 `market_sources.kpl_plate_strength` 中 `strength` 的业务含义，不请求接口、不运行采集器。

## 官方页面

- [告别无效复盘，区间强度助你锁定市场主线](https://www.kaipanla.com/article/38493)：官网说明“强度”是开盘啦独创的多维数值，综合板块权重个股、涨停数量、人气、成交额和市场情绪，用来比较不同板块的强度；页面还说明可查看区间强度、区间净额和区间成交。
- [如何用「开盘啦」看懂每一轮行情](https://www.kaipanla.com/article/39810)：官网将“精选板块强度值”作为板块行情指标举例，并称强度值由多维度综合测算；未披露公式、原始接口字段位置或计量单位。
- [洞悉主力资金，捕捉最强风口起爆点](https://www.kaipanla.com/article/37786)：官网另将“最强风口”个股行中的“强度”解释为个股当时拉升强度。该个股指标与本项目板块接口的 `strength` 是不同业务对象，不能仅凭同名合并。

页面由 `https://www.kaipanla.com` 提供，页脚显示深圳开盘啦网络科技有限公司。官网材料足以确认产品中板块强度指标的大体含义，但没有提供 `RealRankingInfo` 响应的字段表；响应位置仍需由本地适配器与同响应样本证明。第三方接口仓库只用于定位可能的接口线索，本裁决未把它们当作官方字段定义。

## 边界

- 官网定义支持“板块强度综合数值”，不支持复原算法、分值单位或跨源等价关系。
- 本记录不确认 `market_sources` 整体为单一提供方，也不调整来源独立性；结论只针对适配器的 `kpl_plate_strength` 子接口路径。
- 本记录不涉及 KPL 个股涨停明细 `DailyLimitPerformance` 的 `raw_columns.col_02`，也不涉及 KPH（开盘红）。
