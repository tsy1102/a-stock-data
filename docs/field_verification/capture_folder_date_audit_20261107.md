# 采集目录数据日命名审计（2026-11-07）

## 规则

每日采集目录名是目标 `data_date`。默认日期取运行时最近已完成的 A 股交易日：交易日 15:00 起使用当天，15:00 前使用上一个交易日，休市日使用最近一个已完成交易日。同一 `data_date` 的重跑写入同一个目录；逐源采集时刻与来源实际 `as_of_date` 保存在元数据中，不由目录名推导。

ZHB 缓存的 `zhb_YYYYMMDD.zip` 文件名仍表示该缓存自身的数据日期。它可以早于本项目采集目录的数据日，不触发目录改名。

## 历史核查

按仓库保留起点 `20261015` 检查日期目录及其 raw 文件名，并只读取有 raw 文件目录中的 `meta.json`：

|---|---:|

所有保留 raw 目录已符合新命名约定，因此无需重命名或搬移历史采集数据。核查未读取保留起点前的 raw 或 ZHB 缓存，也未修改历史采集文件。

## 实现与回归范围

- `capture_field_probe.py` 默认使用最近已完成交易日并写入该数据日目录；同目录重跑默认仅补采缺失或不完整来源，完整来源的 raw 与已有逐源时间保留。旧 `meta.json` 缺少逐源时间时，只保留带 `legacy_global_metadata` 标记的目录级日期，不补造精确时间。
- 同一来源显式 `--only` 重采时，源文件及其逐源采集元数据随新结果更新；`--overwrite` 保持显式强制刷新语义。
- 碰撞器拒绝目录名与 `meta.data_date` 不一致的行情快照；同一目录内事件来源按各自采集日匹配自然日窗口，交易来源仍按源 `as_of_date` 选择有效交易日。
- 历史周末/休市日期目录若没有明确匹配的数据日，不再按目录日推测前一交易日。
