# 公式关系复算样本

这里保存 `derived_relation` 决策所引用的 CSV。CSV 是复核证据的一部分，必须随决策长期留存，以便确认样本日期、数值误差和公式结果仍可重放。

- 每行对应一个唯一的 `(股票代码, 有效日期/报告期)`；目标和所有输入必须使用同一有效日期/期间。
- 保留原始数值精度，不要把格式化后的报告文字当作样本；需要单位换算时，在决策公式中明确写出换算因子。
- 文件不得包含 API key、Cookie、账户信息或与裁决无关的个人数据。
- 工具限制单个 CSV 为 10 MB、50,000 行，并要求至少 10 行、3 只股票及满足流程文档的日期和公式命中门槛。

字段定义、样本列配置和复核步骤见 [`ADJUDICATION_WORKFLOW.md`](../ADJUDICATION_WORKFLOW.md)。
