## 二、ihelp 原始栏目定义（节选）

- 涨幅：(现价-昨收)/昨收*100
- 涨跌：现价-昨收
- 现量：最近一次分笔成交量
- 换手：成交量/流通股本*100
- 市盈(动)：现价/折算成全年的每股收益
- 振幅%：(最高-最低)/昨收*100
- 量比：开市后每分钟的平均成交量与过去5个交易日每分钟平均成交量之比
- 内盘：主动性卖盘的成交量
- 外盘：主动性买盘的成交量
- 内外比：内盘/外盘
- 流通市值：流通股本*现价
- AB股总市值：公司的A股总市值和B股总市值的和,此栏目不包括在香港上市的那部分市值
- 强弱度：此品种的涨幅减去对应大盘(上证指数,深证成指或北证50)的涨幅的值
- 每笔换手：每笔均量/流通股本*100
- 封单额：涨停或跌停时,买一的金额或卖一的金额
- 封成比：涨停或跌停时,封单量(买一量或卖一量)除以当前的已成交量
- 委比%：(五个买盘之和-五个卖盘之和)/(五个买盘之和+五个卖盘之和)*100 如买盘或卖盘为空,则显示为0
- 总股本：公司的总股本
- 资产负债率：(总资产-净资产-少数股东权益)/总资产*100
- 市净率：即是PB,现价/每股净资产
- 每股收益：当期的净利润/总股本。注：对于CDR和基金类型,为每份收益
- 每股净资：净资产/总股本
- 每股公积：公积金/总股本
- 每股未分配：未分配利润/总股本
- 权益比：净资产/(总资产-少数股东权益)*100
- 净益率：即净资产收益率,当期的净利润/净资产*100
- 股息率：(TTM)近4个季度内公司的累计分红总额/公司总市值*100,对于港美股等,为每股股息除以股价
- 昨封单额：上个交易日的收盘时的封单额,如果为正,表明上个交易日的收盘是涨停状态
- 前封单额：上上个交易日(前天)的收盘时的封单额,如果为正,表明上上个交易日的收盘是涨停状态
- 开盘%：(开盘-昨收)/昨收*100，即竞价涨幅
- 最高%：(最高-昨收)/昨收*100
- 最低%：(最低-昨收)/昨收*100
- 均涨幅：(均价-昨收)/昨收*100
- 实体涨幅：(现价-今开)/今开*100
- 回头波：(现价-最高)/最高*100,即当日的最大回撤
- 攻击波：(现价-最低)/最低*100,即当日的最大收益
- 现均差%：(现价-均价)/昨收*100
- 市盈(TTM)：根据最近12个月的每股收益得到的市盈率
- 市盈(静)：静态市盈率(最近年报的市盈率)
- 连板天：出现连续涨停板的天数,如果当天也涨停,则以紫色高亮显示,如果盘中不是紫色,则表示当日不再涨停(断板)
- 封流比：封单量(买一量或卖一量)占当前股票的自由流通股本的百分比
- 封昨比：涨停或跌停时,封单额除以昨日成交金额(按涨跌停比例进行了折算)
- 量涨速%：最近N分钟的放量比率,涨速的N值可在系统设置1涨速周期分钟数地方设置
- 短换手%：最近N分钟的换手(股本使用自由流通股本)
- 主力净额：超大单和大单买入成交金额-超大单和大单卖出成交金额
- 主力净比%：主力净额/自由流通市值*100
- 流通市值Z：自由流通市值，流通市值减去占5%以上股份(包括一致行动人)等部分的市值，等于流通Z*现价
- 换手Z：按自由流通股本计算出来的换手率
- 流通比例Z：自由流通股本占总股本的比例
- 开盘金额：当前股票早盘集合竞价的成交金额
- 开盘抢筹%：(开盘价-最后一次集合竞价的匹配价)/最后一次集合竞价的匹配价*100
- 开盘昨比%：开盘金额/昨成交金额*100
- 开盘昨封比%：开盘金额/昨日涨停封单额*100
- 竞价涨停买：开盘集合竞价期间的未撤单涨停价买入金额(需Level2行情)
- 竞价昨比：开盘成交量/昨日开盘成交量
- 开盘量比：也称竞价量比，开盘成交量/过去5个交易日每分钟平均成交量(指数为开盘成交额/昨日开盘成交额)
- 开盘换手Z：当前股票集合竞价成交量/自由流通量，即竞价换手Z
- 人均持股：(自由流通股+B股股本(如果有B股))/股东人数
- 人均市值：(当前的自由流通市值+B股市值(如果有B股))/股东人数
- 年振幅%：(52周最高-52周最低)/52周最低*100
- 如果现量大于某一阀值(在系统设置中的设置1中的现量高亮显示),则紫色高亮显示
- 如果行情开盘价为涨停价或跌停价,则对内容加灰框
- 如果行情最高价为涨停价,则对内容加灰框
- 如果行情最低价为跌停价,则对内容加灰框
- 如果开高低收一样并且买一价或卖一价没有时,则在涨幅下画下划线
- 多日涨幅(比如20日涨幅)是按上证指数的交易日来计算,不是按个股自己的交易日
- 涨跌数：该指数成份股中上涨家数和下跌家数
- 开盘金额：该指数所有成份股的早盘集合竞价时的成交金额
- 开盘换手Z：该指数所有成份股的集合竞价成交量/该指数成份股总的流通股本
- 短换手%：最近N分钟的换手
- 主力净比：主力净额/流通市值*100
- 开盘%：(开盘-昨收)/昨收*100
- 今开：指今天的开盘价
- 资金流向：(持仓*价格-昨持仓*昨收)*每手乘数*保证金比例
- 均涨幅%：(均价-昨结算价)/昨结算价*100
- 实体涨幅%：(现价-今开)/今开*100
- 回头波：(现价-最高)/最高*100
- 攻击波：(现价-最低)/最低*100
- 均涨幅%：(均价-昨收)/昨收*100
- H股股本：指上市公司的流通股本，即上市公司在香港市场流通的股份。对于美股市场赴香港市场二次上市的公司，H股股本只算了IPO发行股本
