# ZHB `tdxstat` 股息率与员工人数别名核验（2026-11-08）

## 官方定义与解析路径

通达信官方 `get_more_info_batch` 字段表列出 `DYRatio`（股息率）和 `StaffNum`（员工人数）：<https://help.tdx.com.cn/quant/docs/markdown/mindoc-1hjbidnohpjn4/mindoc-1hlir5r0t9hgc.html>。

本项目 `core/zhb_client.py::_parse_tdxstat()` 从 `tdxstat.cfg` 原始列 `[10]` 解析 `dividend_yield`，从 `[15]` 解析 `employee_count`；采集 JSON 同时保留 `full` 与 `stat` 表示。本次比对这两个完整来源路径与已验证锚字段 `stat.dividend_yield`、`stat.employee_count` 的同源值。

## 日期与样本范围

只纳入数据日期不早于 2026-10-15 的保留期样本。数据日期取 `zhb_YYYYMMDD.zip` 文件名，并要求 `tdxstat.cfg` 行日期与文件名一致；仅使用其日期相同的 `raw_zhb.json` 样本。采集目录日期不能替代数据日期。2026-10-15 目录所含 ZHB 数据日为 2026-10-14，因此排除。

纳入的数据日为 `20261016`、`20261019`、`20261020`、`20261023`、`20261027`、`20261028`、`20261030`、`20261102`、`20261103`、`20261104`、`20261106`；每个数据日 20 只股票，共 220 个股票日配对。按十进制数值精确比较，没有使用舍入容差。

| 来源路径 | 原始列 | 已验证同源锚路径 | 精确匹配 | 双方缺失 | 差异 |
|---|---:|---|---:|---:|---:|
| `dividend_yield` | `[10]` | `stat.dividend_yield` | 220/220 | 0 | 0 |
| `employee_count` | `[15]` | `stat.employee_count` | 220/220 | 0 | 0 |

每组均同时对照 ZHB 原始列、采集结果的 `full` 值和 `stat` 值。两条解析路径与原始列完全一致；样本来自同一 TDX/ZHB 来源，不作为独立提供方之间的交叉验证。

## 裁决边界

- `dividend_yield` 的含义按通达信官方 `DYRatio` 登记为“股息率”；单位 `%` 沿用与其 220/220 精确一致的已验证同源锚字段。该字段数值随行情及分红口径变化，本次确认的是字段语义和路径对应关系，不把采集日之外的某个值说成长期常量。
- `employee_count` 的含义按官方 `StaffNum` 登记为“员工人数”，单位“人”。此字段为低频变化的公司统计值；本次没有推断其报告期或具体更新时点。
- 两项均登记为同源别名，不新增跨源映射；未对官方文档未披露的底层计算口径作额外推断。
