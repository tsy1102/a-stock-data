# ZHB `tipinfo.dat` `[8]/[9]` 字段纠错

**复核日期：** 2026-11-08
**裁定：** `[8]` 是股东持股变动记录关联日期，`[9]` 是股东持股变动数量（万股，带正负号）；二者不是业绩预告日期和预告净利润。

## 当前定义

| 原始列 | 当前解析键 | 含义 | 单位与口径 |
|:--|:--|:--|:--|
| `[8]` | `shareholder_change_date` | 股东持股变动记录关联日期 | `YYYYMMDD`。不同公告可能给出交易日、减持区间截止日或权益变动协议签署日；不能一概当作逐笔交易日。 |
| `[9]` | `shareholder_change_shares_wan` | 股东持股变动数量 | 万股；正值为增持/转入，负值为减持/转出。源值按两位小数舍入。 |

本次定案确认的是日期与带符号股数的字段语义。它不声称掌握通达信内部字段英文名，也不把日期扩展解释为统一的交易日。

## 注册表与历史材料处置

- 按完整来源身份将 `ZHB-tipinfo::[8]`、`ZHB-tipinfo::[9]`、旧输出键 `div_date` / `div_amount` 及嵌套路径 `tipinfo.div_date` / `tipinfo.div_amount` 标记为 `disproved`。这里证伪的是旧“业绩预告日期/金额”解释，不是原始列或数据不存在。
- 新增 `shareholder_change_date`、`shareholder_change_shares_wan` 与采集路径 `tipinfo.*` 的已核字段记录，保留三组公告证据、样本值和日期口径边界。
- 旧 `reference_evidence` 保留作历史记录；`field_source_reference.md`、此前定案报告和碰撞报告不改写。曾把 `tipinfo.div_amount` 与资金流字段关联的旧碰撞结果不再视为同义证据；本裁定取代 2026-11-04 对旧解释的“inconclusive”结论。
- `docs/verify/zhb_verify.md` 由生成器在保留历史原文的基础上覆盖 `[8]/[9]` 当前定义并链接本记录，避免只读档案的旧描述继续被当作现行代码契约。

## 运行时代码影响

`_parse_tipinfo()` 改用 `shareholder_change_date` 与 `shareholder_change_shares_wan`；采集快照后续写入的新路径为 `stocks[code].tipinfo.shareholder_change_*`。项目内没有读取旧 `div_*` 键的有效消费者，ZHB 统计缓存也不缓存 `tipinfo`，无需升级缓存版本。

`get_lng_report.py` 曾从 `get_zhb_single_stock_data()` 结果读取 `ex_date` 和 `div_date` 来决定是否打印不复权提示，但该合并结果只包含 `tdxstat`、`tdxstat2` 与 `report_date`，这两个键从未存在。现改为不复权兜底时直接说明窗口内若有除权除息，跨日比较可能偏差。
