## 二、三处可实证硬错误（附复现证据）

### 2.1 腾讯股本字段 `[72]/[73]` 索引颠倒
**Gemini 主张**（§四表）：`tx[72]`=总股本、`tx[73]`=流通股本、`tx[76]`=A股流通股本。
**项目定案**（field_dict:1163-1164 / 2949-2950 / 5766）：`[72]`=A股流通股本、`[73]`=总股本、`[76]`=A股流通(=72)。

**实证**（解析 `raw_tencent.json` 农行 601288，含 H 股故流通≠总）：
```
601288: [72]=3192.442亿  [73]=3499.830亿  [76]=3192.442亿
        → [72] < [73]，即 [72]=流通、[73]=总股本
```
茅台 600519 全流通故 `[72]=[73]=12.501亿` 无法区分，但 601288 明确证伪 Gemini 的颠倒。**结论：Gemini `[72]/[73]` 写反，若入库将致市值计算根基错误。**

### 2.2 tipinfo `Col[7~9]`、`Col[13~16]` 系统误标为"解禁"
**Gemini 主张**（§六.4）：Col[7]=股东大会召开日、Col[8]=业绩预告日、Col[9]=业绩预告净利润、Col[13]=最近限售解禁上市日、Col[14]=解禁股数、Col[15]=前次解禁日、Col[16]=前次解禁股数。

**项目定案**（field_dict:611-635，含 TdxQuant 单样本实锤 + 日期分布分析）：
- Col[7] = 最近一次**重大事件/异动日**（未定案，非股东大会）
- Col[8] = **分红日** (`div_date`)、Col[9] = **分红金额(每10股,元)** (`div_amount`)
- Col[13] = **股权登记日** (RecentReleaseDate)、Col[14] = **配股/除权登记金额(万元)**
- Col[15] = **(老)增发事件日期**、Col[16] = **(老)增发募集金额(万元)**

**关键证据**：Gemini 自列样本值与字典命名字段**数值重合**（如 000001 的 Col[14]=25224.80、Col[16]=59880.24 与字典 [14]=配股金额、[16]=增发金额逐字一致），但**语义标签不同**——字典的"分红/配股/增发"有 TdxQuant 实锤与单位(万元)支撑，Gemini 的"限售解禁"无对应证据且与字段单位矛盾（25224.80 万股对平安银行意味着 13% 流通股解禁，远不如 2.52 亿配股募资合理）。**结论：Col[2~6] 正确，Col[7~9]/[13~16] 误标，入库将误导事件日历解析。**

### 2.3 `eltdx finance_info_raw` 槽位索引系统性偏移
**Gemini 主张**（§七.2）：槽[0]=流通股本、[1]=总股本、[8]=EPS、[9]=总资产、[10]=流动资产、[11]=固定资产、[12]=无形资产、[13]=股东人数、[14]=流动负债、[19]=净资产、[20]=主营收入、[21]=营业利润、[23]=经营现金流、[25]=存货、[29]=归母净利润。

## 三、方法论缺陷（影响"定案级别"可信度）

1. **`tdxstat Col[2]` 用 Pearson 0.867 宣称 L1 定案**：相关≠同一。项目 field_dict:489 对该字段的 L1 来自**通达信官方确认**（茅台 ZHB=-0.0963 vs 官方 Beta=-0.10），而非相关分析。Gemini 的 0.867 仅作互证可，但不能作为"破解证明"——其报告将 L2/L3 级相关证据拔高为 L1，违反项目"对撞四铁律"（L1 需跨日精确相等，非相关）。

2. **`tdxstat Col[22]` 把任意多位数分解当"形态语义"**：`A*10000+B*100+C` 对任何 5~6 位整数恒成立（如 50913=5×10000+09×100+13），不证明 A/B/C 是"短/中/长三周期 K 线形态"。项目 field_dict:3414 已据 `tdxhy.cfg` 行业/概念树将 Col[22] 实锤为**概念/热点分类码**（50913/110113 等对应具体概念）。Gemini 的"14 种形态"系对巧合数值的过度解读。

3. **"30 个采集日 / 37 万样本"叙事与技术事实不符**：报告开篇称基于 30 采集日跨源对撞，但多处结论（如 §七.2 finance_info_raw 索引、§四 `[72]/[73]`）与项目**既已定案且经实测**的字段直接冲突——说明报告至少有部分内容未真正对齐项目权威字典，或存在幻觉补全。建议将其视为"独立第三方推测"，而非"本项目对撞成果"。
