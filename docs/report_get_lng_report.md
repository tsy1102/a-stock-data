# get_lng_report.py 代码审查报告

## 概览
`get_lng_report.py` 负责生成长线（LNG）报告，约 40KB。实现主要包括参数解析、调用 `layer*` 函数并写入文本文件。

## 主要代码质量问题
1. **缺少类型注解** 与 **函数文档**。 
2. **异常捕获宽泛**，仅 `print` 错误信息。 
3. **硬编码路径**（报告输出目录），未支持配置化。 
4. **重复逻辑** 与 `get_ful_report.py` 的主流程相似，可抽象为通用入口。 
5. **日志使用 `print`**，建议改用 `logging`。

## 改进建议
- 为入口函数 `main` 添加 `def main(codes: List[str]) -> None:` 注解。
- 将参数解析、分析调度、报告写入拆分为独立函数。
- 使用 `logging`，并在捕获异常后抛出自定义异常 `LngReportError`。
- 将输出目录抽象为配置项或环境变量 `REPORT_DIR`。
- 提供单元测试，使用 `unittest.mock` 替代网络请求。

## 风险评估
- **改动规模**：中等（约 120 行），保持 CLI 接口不变。
- **回归风险**：低，只要输出结构保持一致。
- **收益**：提升可维护性、错误可追踪性，便于后续功能扩展。
