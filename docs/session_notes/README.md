# 每日会话纪要(session_notes)保存逻辑

> V16.4.1 建立。目的: 对话上下文会被自动压缩, 纪要 = 跨日记忆锚点,
> 保证任何时刻新开会话/压缩后都能无缝恢复项目状态。

## 目录结构

```
docs/session_notes/
├── README.md          # 本文件(保存逻辑)
└── YYYYMMDD.md        # 每日一份(如 20260812.md)
```

## 保存逻辑(固定流程)

1. **触发**: 用户指令"写今日会话纪要 / 当日会话总结"时执行(每天会话结束前)
2. **生成**: 当日 `docs/session_notes/YYYYMMDD.md`, 内容模板见下
3. **幂等**: 同一天重复生成 → 覆盖更新(追加当日新增内容)
4. **引用**: 涉及的具体数据/结论指向 field_verification/YYYYMMDD/ 与 field_dict.md, 不在纪要里重复大段数据
5. **归档**: 按日期文件名天然归档, 永不删除(历史纪要 = 项目决策时间线)

## 内容模板(固定章节)

```markdown
# YYYY-MM-DD 会话纪要

> 版本: 16.4.x | 会话主题: xxx

## 1. 环境与入口
- 系统/Shell/编码状态(代码页、opencode 子进程编码约定)
- 通达信/同花顺客户端状态(运行/关闭——影响 TdxQuant/thsdk 采集)

## 2. 本日改动(文件级清单)
| 文件 | 改动 | 目的 |
|---|---|---|

## 3. 关键决策(ADR 风格)
- 决策: 背景 → 方案 → 理由

## 4. 数据/破解成果
- 字段破解/字典修正(引用 field_dict.md 状态)
- 采集概况(field_verification/YYYYMMDD/)

## 5. 遗留待办(明日优先)
- [ ] 按优先级列出

## 6. 踩坑记录(防重复)
- 现象 → 根因 → 修法(引用 AGENTS.md 速查表新条目)
```

## 与新会话的衔接

新会话开始时:
1. 读 AGENTS.md §12(活跃待办) + 最新一份 session_notes/YYYYMMDD.md
2. 如需恢复更早上下文, 按需读历史纪要
3. 项目事实均已在文件系统(field_dict/代码/采集数据), 纪要只补"对话态信息"
