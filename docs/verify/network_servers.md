## 四、实测结论（2026-08-11，新 IP 223.64.153.4 无锡移动）

1. **TDX 5 台 + 同花顺 16 台全部可达**——项目两条核心 TCP 链路在移动线路正常
2. **东财 TCP 服务器全不通**（SSO/App/His/Mine/代理）——东财机房在浙江电信/联通/网通段，
   **移动跨网受限**（运营商互联互通问题），与东财 HTTP 风控无关（HTTP 走 CDN 不受影响）
3. 东财客户端在移动网络"只 ping 通一个服务器"= 跨网路由的客观现象，正常
4. **TDX 服务器列表无需因换线路重筛**（可达性已证）；但"数据完整性 FULL"标准建议复测一次
5. 移动线路对东财 TCP 直连不可用 → 若未来需要东财行情 TCP（Level2），需走其 HTTP API 或代理通道
