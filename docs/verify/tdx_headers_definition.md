# 通达信表头字段官方定义(2026-08-14 用户提供)

> 来源: 用户提供的通达信软件表头说明文件(官方定义)
> 用途: TDX 接口字段破解的权威参照——与 field_dict/tdxquant/ZHB 交叉验证

## 行情类(已与 tdxquant/ZHB 实锤对应)

| 字段 | 官方定义 | 对应 |
|---|---|---|
| 涨幅 | (现价-昨收)/昨收*100 | ZAF/f170 ✓ |
| 涨跌 | 现价-昨收 | ulist f4 ✓ |
| 总量 | 当日成交量 | Volume ✓ |
| 现量 | 最近一次分笔成交量 | **NowVol** ✓(现手) |
| 涨速 | (现价-N分钟前价)/N分钟前价*100, N 可设置 | **Zangsu**(价格涨速) ✓ |
| 换手 | 成交量/流通股本*100 | f168/fHSL ✓ |
| 市盈(动) | 现价/折算全年每股收益 | **f162** ✓(年化=Q1×4 验证) |
| 振幅% | (最高-最低)/昨收*100 | 计算 ✓ |
| 量比 | 开市后每分钟均量/过去5日每分钟均量 | f50/fLianB ✓ |
| 内盘/外盘 | 主动卖/买盘成交量 | Inside/Outside ✓ |
| 内外比 | 内盘/外盘 | 计算(15997/19063=0.839) |
| 委比% | (五买-五卖)/(五买+五卖)*100 | Wtb/f191 ✓ |
| 封单额 | 涨停/跌停时买一或卖一金额 | **tdxstat2 [4]/[6]/[8]** ✓(三日滚动, 正=涨停/负=跌停) |
| 昨封单额/前封单额 | 上/上上交易日收盘封单额, 正=涨停 | **[6]=T-1、[8]=T-2** ✓✓ 官方确认 |
| 距5日线% | (现价-MA5)/MA5*100 | **MA5Value** ✓ |
| 量涨速% | 最近N分钟放量比率 | **vzangsu** ✓✓ 官方确认 |
| 贝塔系数 | 近60天 vs 对应大盘 | **BetaValue** ✓ |
| 年涨停天 | 近一年涨停次数(不含未开板) | **YearZTDay** ✓✓ 官方确认 |
| 开盘% | (开盘-昨收)/昨收=竞价涨幅 | VOpenZAF ✓ |

## 本次新破解/修正(V17.0 说明文件驱动)

| 字段 | 官方定义 | 结论 |
|---|---|---|
| **开盘金额** | 早盘集合竞价成交金额 | **OpenAmo=开盘金额(元)/Yield=万**——**重大修正: 非主力净流入!** ZHB[14] 同值=竞价额(19/19 恒正+占比<5% 铁证) |
| **主力净额** | 超大单+大单买入-超大单+大单卖出 | 东财对应 **f137+f140**(超大净+大单净); ZHB 无此列(仅开盘金额列) |
| 短换手% | 最近N分钟换手(自由流通股本) | **Fzhsl 候选**(Fz=分钟+HSL=换手; 茅台 0.02%/妖股 0.79% 吻合) |
| 2分钟金额 | 最近2分钟成交金额 | **FzAmo 候选**(Fz=分钟+Amount) |
| 实体涨幅 | (现价-今开)/今开*100 | **公式修正**(原猜 (收盘-开盘)/昨收) |
| 现均差% | (现价-均价)/昨收*100 | **公式修正**(原标"现价-均价") |
| 活跃度 | 当日成交分笔数 | L2TicNum/L2OrderNum 候选 |
| 每笔均量 | 成交总量/分时笔数 | 计算型 |
| 封成比 | 封单量/已成交量 | tdxstat [33] 候选 |
| 连板天 | 连续涨停天数(当天也涨停紫色) | **[31]≠连板天**(002827 非涨停日仍+1, 排除) |
| 几天几板 | 首封后3日内又封板统计 | [32]/[33] 候选 |
| 流通市值Z/换手Z/流通比例Z | Z=自由流通 | **Z 后缀=自由流通** ✓(FreeLtgb 确认) |
| 封流比 | 封单量/自由流通股本 | sht 封流比 ✓ |
| 人均持股 | (自由流通+B股)/股东人数 | 计算型 |
