### 🌟 双日 Delta 重大发现：T/T-1 自动滚动对

通过比对 13 号和 14 号数据，发现了**完美的跨日滚动规律**（10只股票全部验证通过）：

```
14号的 [10] = 13号的 [9]  (10/10 True)
14号的 [15] = 13号的 [14] (10/10 True)
```

这意味着 `[9]/[10]` 和 `[14]/[15]` 是两组**"今日/昨日"数据对**，与 `[3]/[5]/[7]`（近3日成交额）类似的时序结构。

### 🌟 资金流向（主力净流入）彻底破解：[9] 和 [14] 的完美公式

通过深度的逆向工程和公式验算，我们彻底破解了 `tdxstat2` 中最核心的资金流向密码！

**验证公式：** `[9] * 100 * 股票收盘价 / 10000 ≈ [14]`

在 10 只样本股中，该公式**100% 完美成立**（误差 < 1%，因为 `[14]` 是根据每笔实际成交价计算的精确值，而我们使用收盘价估算）：
* **茅台**: `[9]=576`,估算值 `6940万` vs `[14]=6895万` (Ratio=1.01)
* **宁德时代**: `[9]=6390`,估算值 `22285万` vs `[14]=22301万` (Ratio=1.00)
* **工行**: `[9]=28270`,估算值 `2072万` vs `[14]=2066万` (Ratio=1.00)

**最终定论：**
| 索引 | 确切含义 | 策略价值 |
| :--: | :--- | :--- |
| **[9]** | **T日 主力/大单净买入量 (单位：手)** | ⭐⭐⭐⭐⭐ 核心资金面指标（正为净买入，负为净卖出） |
| **[14]** | **T日 主力/大单净流入额 (单位：万元)** | ⭐⭐⭐⭐⭐ 绝对资金流向 |
| **[10]** | **T-1日 主力/大单净买入量 (手)** | ⭐⭐⭐⭐⭐ 昨日资金指标（验证为T-1滚动） |
| **[15]** | **T-1日 主力/大单净流入额 (万元)** | ⭐⭐⭐⭐⭐ 昨日资金指标（验证为T-1滚动） |
